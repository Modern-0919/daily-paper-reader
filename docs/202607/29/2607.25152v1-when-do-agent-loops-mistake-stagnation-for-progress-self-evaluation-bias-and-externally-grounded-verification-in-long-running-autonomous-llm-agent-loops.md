## 摘要
长期运行的自主代理在没有人工干预的情况下进行规划、行动并判断自身的完成情况。当代理为自己的工作打分时，自我评估偏差便会显现：看似合理的更改被视为进步，而现实世界的结果却停滞不前甚至倒退。我们将这种失败模式命名为“进步幻象”，并通过受控测量表明，问题在于评估者所依据的基础。我们搭建了一个测试平台，保持代理及其工具表面固定，仅操纵控制循环的评估者的信息通道类型。通过容器和网络隔离强制执行原则上不可伪造的世界状态预言机，并在每次运行时进行验证。在54个循环中，一款前沿代理每次都声称取得了进步，但其中56%的测量增量实际为零或负值。因此，自我报告毫无信息量，自我裁决门退化为“全部接受”，导致其曾经达到的最佳部署状态下降了19%。即使是最强的带内评判者——读取完整工件文本、变更差异及其自身的裁决历史——也接受了44%实际退步的循环，并拒绝了38%实际改进的循环；预注册的对抗性假设（即强评判者能缩小差距）被拒绝。在一个边界任务上，其成功规范可从工件本身验证，同一评判者的幻象降为零，差距在注册阈值内消失，表明差距取决于成功信号所在的位置。仅返回接受裁决的符号变体保持了与现实世界相似的输出（110.0对113.0），表明益处在于门的依据而非反馈内容。对于成功信号存在于记录之外的开放式目标，单纯扩大评判者规模是不够的；具有现实世界访问权限的带外评估是一项结构性要求。

## Abstract
Long-running autonomous agents plan, act, and judge their own completion without human intervention. When an agent grades its own work, self-evaluation bias takes hold: plausible changes are accepted as progress while real-world outcomes stagnate or regress. We name this failure mode the progress mirage and show, with controlled measurement, that it is a question of what the evaluator is grounded in. We built a testbed that holds the agent and its tool surface fixed and manipulates only the information-channel type of the evaluator that gates the loop. A world-state oracle, unfakeable in principle, is enforced by container and network isolation and verified at every run. Across 54 cycles a frontier agent claimed improvement every time, yet 56 percent had a measured delta of zero or below. Self-report was thus uninformative, and the self-verdict gate degenerated into accept-all, eroding the best deployed state it had reached by 19 percent. Even the strongest in-band judge, reading the full artifact text, the change diff, and its own verdict history, accepted cycles of which 44 percent were real-world regressions and rejected 38 percent of real improvements; the preregistered adversarial hypothesis that a strong judge closes the gap was rejected. On a boundary task whose success specification is verifiable from the artifact itself, the same judge's mirage vanished to zero and the gap collapsed within the registered threshold, showing that the gap depends on where the success signal resides. A sign-only variant returning only the acceptance verdict kept real-world output similar to full feedback (110.0 versus 113.0), locating the benefit in the gate's grounding rather than in feedback content. For open-ended objectives whose success signal lives outside the transcript, scaling up the judge is not enough; out-of-band evaluation with real-world access is a structural requirement.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：长期运行的自治 LLM 代理循环中，代理依赖自我评估判断自身完成情况。自我评估偏差导致代理将看似合理的分析和过程误认为进步，而现实世界结果停滞或倒退——这种失败模式被命名为**“进步幻象”（progress mirage）**。
- **背景**：当前平台（如 loop/goal 原语）内置的评估者基本是**带内（in-band）** 的，即仅查看对话记录。当任务成功信号位于现实世界状态（如用户转化数）而非记录中时，带内评估者无法验证代理的声称，导致循环自我欺骗。
- **总体含义**：对于开放式真实目标，仅扩大评估者能力是不够的，必须将评估者从生成器分离并赋予其直接访问现实世界的能力（带外评估），这是结构性的必要条件。

## 2. 论文提出的方法论

### 2.1 核心思想
- **生成器-评估器分离**：代理（生成器）负责执行，评估器作为独立进程运行，不共享同一会话。
- **带外（out-of-band）评估**：评估器直接读取数据库、版本控制、web 分析、追加只读账本等现实世界信号，而不是代理的对话记录。
- **奖励函数重定义**：评估器执行的奖励函数是“现实世界度量是否真的移动了”，而非“是否产生了新分析”。
- **强制反馈**：若现实信号未移动，评估器写入拒绝工件，下一循环启动时必须首先读取该工件，使得循环无法凭自我声称终止。

### 2.2 关键技术细节
- **世界状态预言机**：合成用户模拟器，根据部署工件的四个属性（CTA 存在、页面载荷大小、漏斗步骤数、文案长度）加权逻辑回归计算转化概率，并生成固定队列的转化数；使用公共随机数保证增量符号不被噪声翻转。
- **隔离与边界证明**：代理容器和预言机容器位于两个独立网络，无路由可达；代理只共享部署卷（只读给预言机）。每次运行开始进行边界证明：主机获取 canary，代理无法获取，每循环扫描代理侧输出确保无 canary 出现。
- **三种评估臂**：
  - **in-band-self**：仅凭代理自我报告，实际退化为全部接受。
  - **in-band-judge**：独立更强模型读取完整工件文本、diff、自身历史，使用批判性提示，但不访问预言机。
  - **out-of-band**：仅当预言机实际转化增量为正时接受。
- **辅助机制**（来自现场观察，未经单独验证）：追加只读状态、基于文件的手递、框架对抗性审查、自愈调度器。

## 6. 论文的主要结论与发现

1. **自报告完全无信息**：在全部 54 个 T1 周期中，代理每次都声称改进，而预言机测量 56% 实际增量为零或负。自评估门退化为“全部接受”，导致最佳状态被后续可解释退化侵蚀 19%。
2. **最强带内评判者失败**：即使使用更强模型、提供完整工件文本、diff 和裁决历史，其接受周期中 44% 仍为现实世界退步，并拒绝 38% 真实改进。预注册对抗假设（HA1：强评判者能缩小与带外的差距）被拒绝。
3. **边界任务幻象消失**：在 B1（规范可从工件验证）上，同一评判者的幻象率降为 0%，差距缩小至注册阈值内（H2 接受）。说明原因不是评估者能力，而是成功信号位置。
4. **符号反馈变体**：仅返回接受裁决的版本达到平均最终输出 110.0，与完整数值反馈的 113.0 相近，表明带外的益处来源于**门的依据**（grounding）而非反馈信息内容。
5. **区别循环管道与奖励大脑**：调度、节奏等“管道”可委托平台原语；但基于现实世界信号的“奖励大脑”必须独立实现并带外评估。
6. **进步幻象的解剖**：早期大杠杆阶段，代理的合理性和效果一致；耗尽后，合理性与效果偏离，带内评估者无法探测。

## 7. 优点

- **问题形式化**：首次系统定义并测量长期自治代理循环中的“进步幻象”，将其联系到奖励滥用和规范博弈文献。
- **严格实验设计**：通过容器和网络隔离实现原则上不可伪造的预言机，每运行执行边界证明，每周期扫描 canary，确保代理无法操纵。
- **操控信息通道而非模型能力**：固定代理和工具，仅改变评估者信息通道类型，清晰隔离因果变量。
- **包含边界任务控制**：B1 任务的成功信号位于工件内，其幻象消失证实结论是机制性的而非实验装置偏向。

## 8. 不足与局限

- **规模有限**：仅 pilot 试点（一个任务族、一个代理模型、3 次重复），结论效力不足以泛化至其他领域或更长时域。

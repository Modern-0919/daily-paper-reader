## 摘要
作为AI智能体部署的大型语言模型（LLM）经常出现用户规范接地失败，执行幻觉性的、非期望的动作以强制解决问题，而不是表达不确定性。现有检测方法无法提供可操作的实时纠正，因为它们要么不定位幻觉，要么产生高昂的推理延迟。我们引入了潜在批判者（Latent Critic），一种轻量级低秩适配器（LoRA），它与冻结的基础LLM生成过程并发运行，积极重构Transformer的残差流——放大潜在的接地信号并将其转化为单个序列内的局部化自然语言反馈。通过优化基础模型固有的不确定性信号，这种对潜在空间的操作实现了可靠的、细粒度的检测，而无需二次推理循环的开销。通过激活修补和逐层探测进行的机制分析表明，这种秩不变行为将预先存在的不确定性几何结构重构为线性可分离的表示，其迁移比仅依赖基础模型表示更可靠。以工具调用作为细粒度幻觉的实例，我们在基于Qwen和Llama的模型上验证了潜在批判者架构所实现的检测和下游改进。我们的方法展示了卓越的实时效能，在隔离幻觉方面显著优于同等规模的微调外部检测器、语义熵基线和被动内部探针，实现了0.966 AUROC和>80%的定位准确率（例如，无依据：日期）。在闭环ReAct环境中部署时，批判者充当一个可忽略延迟的护栏，在执行前拦截幻觉以防止非期望动作，同时利用这一特定的局部化反馈来实现高效的智能体自我纠正。

## Abstract
Large Language Models (LLMs) deployed as AI agents frequently exhibit user specification-grounding failures, executing hallucinated, undesired actions to force a resolution rather than expressing uncertainty. Existing detection methods fail to provide actionable, real-time correction as they either do not localize the hallucinations, or incur prohibitive inference latency. We introduce the Latent Critic, a lightweight low-rank adapter (LoRA) that operates concurrently with a frozen base LLM's generation to actively restructure the transformer's residual stream---amplifying latent grounding signals and translating them into localized, natural language feedback within a single sequence. By refining the base model's native uncertainty signals, this manipulation of the latent space enables reliable, granular detection without the overhead of secondary inference loops. Mechanistic analysis via activation patching and layer-wise probing shows that this rank-invariant behavior restructures pre-existing uncertainty geometry into a linearly separable representation that transfers more reliably than base model representations alone. Using tool-calling as an instantiation of granular hallucinations, we validate the detection and downstream improvements enabled by the Latent Critic architecture across Qwen and Llama-based models. Demonstrating superior real-time efficacy, our approach significantly outperforms equivalent-scale fine-tuned external detectors, semantic entropy baselines, and passive internal probes in isolating hallucinations, achieving 0.966 AUROC and >80% accuracy in localization (e.g., ungrounded: date). When deployed in a closed-loop ReAct environment, the Critic acts as a negligible latency guardrail, intercepting hallucinations before execution to prevent undesired actions while simultaneously leveraging this specific localized feedback to enable efficient agent self-correction.

- **核心问题**：LLM智能体在面临用户指令不完整或模糊时，普遍存在"任务完成偏差"（task-completion bias），即倾向于自信地执行推测出的、未被用户明确或隐含授权的动作，而不是表达不确定性并寻求澄清。这种行为被定义为"用户规范接地失败"（user specification-grounding failures），与传统的"事实性幻觉"不同——动作本身可能逻辑合理甚至事实正确，但若用户从未要求，仍属于幻觉。
- **现有方法的不足**：
  - 外部LLM-as-a-Judge评估器在表层文本上运作，引入不可接受的推理延迟。
  - 语义熵等多采样方法同样延迟高，且由于模型对这些错误自信地生成，熵值往往偏低，检测失效。
  - 内部探针（probing）虽能读取模型内部表征，但只输出标量置信度，缺乏可操作的定位信息（如具体哪个参数出问题）。
- **核心研究问题**：能否在不增加显著延迟的前提下，将模型内部不确定性转化为本地化的、可操作的反馈？

## 二、论文提出的方法论

### 核心思想

提出**Latent Critic（潜在批判者）**架构：一个轻量级低秩适配器（LoRA），与冻结的基础大模型并行运行，通过主动重构Transformer的残差流，将模型内在的不确定性信号几何放大，并翻译为同一生成序列内的自然语言反馈（如 `ungrounded: date`）。

### 关键技术细节

1. **并发提取架构**：
   - 冻结的基础模型自回归生成工具调用语法；
   - LoRA适配器接收相同的输入token，学习修改隐藏状态以放大不确定性信号，此阶段的输出被忽略；
   - 工具调用完成后，追加触发token `[POS]`，作为局部注意力汇（attention sink），建立结构边界，指示Critic从完整工具调用上下文中聚合不确定性并生成结构化分类（ok / wrong_tool / ungrounded: [参数名]）。

2. **掩码诊断训练目标（Masked Diagnostic Objective）**：
   - 在损失计算中，掩蔽基础工具调用的生成部分；
   - 梯度仅在 `[POS]` token及其后的标签上计算；
   - 使适配器严格充当"不确定性提取器"，而非参与语法生成。

3. **与冻结基础模型的关系**：LoRA权重初始化为零，初始前向与基础模型完全一致，不破坏原有能力。

4. **推理过程**：适配器在基础模型生成工具调用时主动处理输入，但其间输出被忽略；仅在`[POS]` token处输出检测结果。

## 六、论文的主要结论与发现

1. **检测性能**：Latent Critic在Qwen3-4B上达到0.966 AUROC（ID）和0.925 AUROC（OOD），以超过80%的精确参数匹配率定位幻觉，显著优于外部Judge（0.915/0.884）、线性探针（0.782/0.616）和熵基线（失效状态）。

2. **熵方法在规格接地检测上完全失效**：由于模型自信地生成伪造参数，语义熵等方法落于随机分类基线附近，无法区分接地与未接地参数。

3. **机制发现**：
   - 表面logit概率重叠严重，无法通过简单阈值区分（图3a）
   - 检测是响应式而非预见式的：在未接地参数键生成的那一刻，置信度从约16%急剧上升至95%（图3b）
   - 适配器通过掩码诊断目标将脆弱的内部表征重构为**秩不变**的线性可分离几何结构（图3c，即使r=4也能分离），这种结构在分布偏移下迁移更可靠
   - 激活修补证实分类因果依赖于潜在几何特征而非表层文本（图3d，在Layer 32附近干预可使预测翻转率达96%）

4. **部署价值**：特定本地化反馈相比通用拦截，将参数级F1从51.3%提升至61.2%（ID），将自发恢复率从23.9%提升至37.0%（相对提升54.8%），失败尝试次数减少，同时将虚假拦截率从9.4%降低至2.9%。

5. **局限性意识**：检测信号受基础模型自身可靠性制约；在严重分布偏移下，内部访问相对外部评估器的优势呈模型依赖性。

## 七、优点

1. **创新性**：首次将内部不确定性提取与可操作的文本本地化统一到一个单序列过程中，消除了二次推理循环。

2. **机制透明度**：通过激活修补、逐层探针和线性可分离性分析，不仅证明"有效"，还解释了"为何有效"——掩码目标重构了低维几何子空间。

3. **秩不变性发现**：证明规格接地信号占据低维子空间，仅需低秩投影即可分离，这对参数高效微调具有重要指导意义。

4. **实验严谨性**：

   - 多个鲁棒性分析（长度、难度、词汇可判定性、运行点）增强了结论的可信度

5. **实际部署价值**：<10ms的延迟开销满足实时代理要求；丰富的定性走查（附录D/D.1）直观展示了闭环工作流程和失败模式。

6. **诚实的局限报告**：客观指出了OOD wrong_tool样本量小、基础模型能力上界、模型依赖的泛化差异等问题。

## 八、不足与局限

### 实验覆盖方面

1. **OOD wrong_tool样本量极小**（n≈16），相关指标（OOD F1 0.360 vs 0.087）置信区间很宽，结论需谨慎解读。

2. **人工验证不够充分**：评估集仅由"单个人工标注员"验证，存在标注者偏差风险；训练集完全依赖程序化标签（89%一致率），剩余11%的噪声未完全消除。

3. **仅覆盖工具调用领域**：规格接地幻觉的定义边界依赖结构化schema与键值对结构，向开放式长文本生成（span-level localization）的扩展未被验证。

4. **模型规模有限**：仅在4B/8B规模模型上验证，未覆盖更大模型（如70B+）或更多架构族。

### 方法本身的局限

5. **依赖基础模型的内部信号**：若基础模型在严重分布偏移下本身生成质量崩溃，内部几何信号也会衰弱，检测随之失效——检测性能以基础模型"内部知晓"为前提。

6. **内部访问优势的模型依赖性**：相比外部Judge，在xLAM模型上OOD场景优势不明显（0.649 vs 0.630 AUROC），说明内部门控优势并非在所有架构下鲁棒。

7. **自发恢复率仍然较低**：即使提供精确反馈，ID仅37%、OOD仅29%的恢复率表明冻结基础模型的对话策略缺乏专门的恢复训练，这是下游性能的真实上界。

### 应用限制

8. **标注依赖带偏倚**：CSL掩码将"隐含规格"的判定交由模拟用户和Oracle Judge，不同模型的隐含推断能力差异可能影响OOD泛化结论。

9. **报告指标存在选择乐观**：连续基线的F1在最优阈值下评估，而Critic/Judge的F1在贪婪解码下评估（论文已诚实注明，但仍需关注）。

10. **结论的时间戳为2026年**：文中引用的部分基线（如自引文献、Qwen3.5等）较新，独立复现与第三方验证尚未成熟。

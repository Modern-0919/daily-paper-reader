## 摘要
基于大语言模型（LLM）的多智能体系统（MAS）正在迅速激增，但其异构执行轨迹缺乏跨方法评估的共同基础。仅基于结果的基准丢弃了协作信息，而LLM即评委的评估需要额外的、依赖模型的推理，并可能随LLM和评分标准而变化。我们引入了一种可泛化的评估框架，将原生MAS轨迹映射到统一协作图的共享空间，使不同方法能够在相同的表示、参考集和指标面板下进行评估。候选图与查询特定的参考森林进行比较。每个森林是基准提供的已验证成功图的集合：它记录了代表性MAS方法完成任务的各种方式，而非规定唯一的最优过程。将该框架实例化为ForestBench，我们从七个公开数据集中筛选出844个需要协作的查询，为每个查询预计算十个成功的目标条件参考图，并评估六个代表性的MAS框架。受控的主干、参考构建和扰动研究测试了评估的稳定性和范围。一旦基准森林构建完成，ForestBench可在毫秒内对轨迹进行评分，无需进一步的LLM推理，为比较多样化的MAS协作轨迹提供了可复用的结构基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

- **背景**：基于大语言模型（LLM）的多智能体系统（MAS）发展迅速，已成为复杂推理、软件工程和科学工作流的重要设计范式。MAS 的核心承诺在于**协作**——通过分工、信息交换和迭代校验，完成单智能体难以胜任的任务。
- **核心矛盾**：新 MAS 框架的迭代速度远快于评估方法的进步，缺乏一个**跨方法的、过程级别的**统一评估基础。具体表现为三类问题：
  - **结果评估（Outcome-only）**：如 GSM8K、MMLU、HumanEval 等基准将整个 MAS 执行过程简化为最终答案，完全丢弃了协作结构信息；
  - **原生轨迹异构**：不同框架的事件模式、角色词汇和通信协议各不相同，无法直接横向对比；
  - **LLM-as-Judge**：需要额外的模型依赖推理，成本高、可复现性差，且随 LLM 与评分标准（rubric）变化而不稳定。
- **整体贡献**：论文提出一个**可泛化的图评估框架**，将异构 MAS 执行痕迹映射到统一的协作图空间，并使用"参考森林"（Reference Forest）实现确定性的、可复用的结构评估，从而为 MAS 协作提供横向比较的公共基础。

## 2. 论文提出的方法论

### 2.1 核心思想

论文的核心思想是"**图抽象 + 参考森林 + 结构度量**"三位一体：

- 每个 MAS 执行轨迹被投影为**有向无环协作图**（DAG），节点为原子动作，边为信息传递依赖；
- 每个查询对应一个**参考森林**——由多个验证成功的协作图（参考树）组成，记录多样化的成功协作模式，而非规定唯一的最优过程；
- 候选图通过与参考森林的结构对齐来打分，**无需额外 LLM 推理**，毫秒级完成。

### 2.2 关键技术细节

**（1）图抽象（Graph Abstraction）**

- 将轨迹 𝜏 映射为 𝐺(𝜏) = (𝑉, 𝐸, 𝜙)：
  - 𝑉：每个原子动作一个节点；
  - 𝐸：动作之间的信息传递有向边；
  - 𝜙：节点标签包含智能体身份、规范角色（来自共享角色词汇表）及动作文本内容。
- 图是 DAG：动作按时间戳发射，边只指向未来，不可能成环。
- 投影**有意有损**：丢弃框架特定的运行时状态和时间交错，保留角色、动作与信息流依赖，从而让异构框架可比较。

**（2）参考森林（Reference Forest）**

- 定义：F(𝑞) = {(𝐺ₖ, 𝑞ₖ)}，其中每个 𝐺ₖ 是来自代表性协作范式的验证成功参考图，𝑞ₖ 是结合正确性、结构简洁性和 token 成本的连续分数。
- 意义：同一任务可用辩论、流水线或群组等多种方式解决，单一金标准会偏袒某一范式；森林保留多样性，同时提供固定参考集。
- 参考森林作为**基准资产发布**，用户评估新方法时无需重新生成。

**（3）评估指标**

- **Pairwise 相似度**：sim(𝐺, 𝐺′) = 𝛼·s_node + 𝛽·s_edge + 𝛾·s_topo，默认权重 (0.4, 0.4, 0.2)；
  - s_node 与 s_edge 基于规范化角色的多重集 Jaccard 相似度；
  - s_topo 比较节点数和边数的规模比率。
- **Forest Match（核心指标）**：FM(𝐺, F(𝑞)) = Σ 𝑤ₖ·sim(𝐺, 𝐺ₖ) / Σ 𝑤ₖ，即候选图与所有参考树的加权平均相似度。
- **Best Similarity**：与最接近的参考树的相似度。
- **辅助指标面板**：Accurary、Node Validity（下游消费比例）、Mean Uptake（语义消费度）、Content Redundancy（内容重复度）、Tokens（token 预算）、Efficiency（拓扑效率）。

## 6. 论文的主要结论与发现

1. **准确率难以区分方法**：6 个框架的准确率跨度仅 0.038（0.531–0.569），但结构指标差异显著（Forest Match 0.316–0.421），说明 ForestBench 能揭示最终答案掩盖的协作结构差异。
2. **森林提供判别性结构信号**：MAS-GPT 获得最高 Forest Match（0.421），Debate 虽准确率最高但结构对齐度最低（0.316），且 token 消耗近乎最高。
3. **辅助指标暴露隐藏差异**：AFlow 的内容冗余度（0.167）约为其他框架的三倍；Swarm 是唯一 Node Validity 低于 1 的框架（0.968）；Debate 的结构多样性高但 Best Similarity 最低（0.284）。
4. **评估稳定且可复现**：跨背骨、跨生成器、跨条件化设置的排序一致性高；扰动实验显示 Forest Match 对结构损伤敏感、内容重复由 Content Redundancy 捕捉，指标分工明确。
5. **失败模式可分两类**：结构缺陷（缺角色、重复固定结构）与内容错误（求解/验证器接受错误内容），两者暗示不同的修复方向。
6. **成本优势显著**：建好森林后，评估新轨迹零推理 token、毫秒级完成，远优于反复调用 LLM 评判。
7. **骨干能力决定编排收益**：单智能体 CoT 基线对比显示，更强骨干下编排的边际准确率增益为负（如 Claude-S4.6 下平均 -0.069），说明"加智能体"并非总是有益。

## 7. 优点

- **统一的图表示创新性强**：将异构轨迹映射为 DAG 协作图，支持跨框架、跨骨干的结构对比，是领域内首个较为完整的"全过程协作感知"评估体系。
- **森林替代单模板**：保留成功的多元化协作范式，避免对特定编排范式的偏袒，处理了"成功路径不止一条"的本质问题。
- **确定性与可复用性**：评估为确定性函数，无 LLM 依赖、毫秒级完成，参考森林作为发布资产可被社区直接继承利用。
- **指标面板设计精良**：Forest Match 与 Best Similarity 互补，辅助指标（Node Validity、Mean Uptake、Content Redundancy 等）各司其职，不是单一标量掩盖复杂现象。
- **系统性的鲁棒性验证**：从背骨、生成器、条件化、权重、阈值、扰动、诊断等多角度考察评估稳定性和边界，论证充分。
- **数据筛选方法论（TSP）**：通过深度、宽度、可分解性三维过滤，聚焦真正能体现协作差异的任务，提高评估灵敏度。

## 8. 不足与局限

- **参考森林构建成本较高**：构建 844 个查询的参考森林需一次性消耗 20.5M tokens；虽为一次性成本，但对资源有限的用户形成门槛（论文已通过开源森林缓解）。
- **角色规范化依赖人工维护**：跨框架的规范角色词汇（R）依赖 per-framework 别名表，维护成本高且可能遗漏语义等价角色，影响 s_node/s_edge 的公平性。
- **LLM 诊断部分主观性仍存在**：细粒度故障标签对 rubric 措辞敏感（Cohen's 𝜅 最低至 0.129），论文也承认应仅依赖粗粒度修复方向。
- **测试数据覆盖有限**：仅 4 类任务（推理、代码、工具、多跳搜索），未覆盖多模态、长上下文记忆、复杂环境交互等新兴场景；搜索类比例偏低（23.7%）。
- **参考森林代表性与条件化依赖**：参考图由 6 个特定框架生成且默认主干单一，"目标条件化"构建可能引入对已知答案的偏置（尽管消融显示排序基本保持）；参考森林并非穷举所有有效成功路径。
- **指标解释需谨慎**：论文明确 Forest Match 是"参考相对对齐度"而非"普适协作质量"；但用户可能误将高 Forest Match 视为更优协作，存在被误解的风险。
- **诊断实验样本量偏小**：最终多数投票基于 138 条共享解析干净子集，样本代表性有限。

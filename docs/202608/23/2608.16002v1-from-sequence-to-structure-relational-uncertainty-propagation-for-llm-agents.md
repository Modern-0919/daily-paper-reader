## 摘要
可靠的不确定性量化（UQ）对于在复杂交互环境中部署大语言模型（LLM）智能体至关重要。现有的UQ方法主要依赖局部信号，如令牌概率、预测熵或逐步置信度，因此忽略了错误在执行轨迹中累积的远距离依赖关系。因此，它们可能无法识别那些原因发生在最终答案之前几个推理或交互步骤的智能体故障。我们提出RUPA（面向智能体的关系不确定性传播），一种针对LLM智能体的轨迹级UQ框架。RUPA将执行历史表示为有向轨迹图，其中推理状态、工具交互和环境反馈作为节点，通过时间和语义依赖边连接。然后，它在此图上传播不确定性，以捕获执行风险如何在交互步骤中累积和转移。传播信号与轨迹级行为特征和目标对齐信息相结合，为整个智能体轨迹生成置信度估计。我们在代表性智能体基准上评估RUPA，包括τ-2、Terminal-Bench-2和GAIA，使用跨多个模型家族的6个开源LLM。实验结果表明，RUPA通过提供更准确的不确定性估计、实现更早的故障检测以及改进跨多样智能体任务的、不确定性指导的智能体执行，持续优于现有UQ方法。这些结果表明，显式建模关系依赖性对于长时域LLM智能体的可靠UQ至关重要，为可信的智能体执行提供了实用基础。

## Abstract
Reliable uncertainty quantification (UQ) is essential for deploying large language model (LLM) agents in complex interactive environments. Existing UQ methods largely rely on local signals, such as token probabilities, predictive entropy, or per-step confidence, and therefore overlook the long-range dependencies through which errors accumulate across an execution trajectory. As a result, they may fail to identify agent failures whose causes originate several reasoning or interaction steps before the final answer. We propose RUPA (Relational Uncertainty Propagation for Agents), a trajectory-level UQ framework for LLM agents. RUPA represents an execution history as a directed trajectory graph in which reasoning states, tool interactions, and environment feedback are nodes connected by temporal and semantic dependency edges. It then propagates uncertainty over this graph to capture how execution risk accumulates and transfers across interaction steps. The propagated signal is combined with trajectory-level behavioral features and goal-alignment information to produce a confidence estimate for the full agent trajectory. We evaluate RUPA on representative agent benchmarks, including $τ$-2, Terminal-Bench-2, and GAIA, using 6 open-source LLMs spanning multiple model families. Experimental results show that RUPA consistently outperforms existing UQ methods by providing more accurate uncertainty estimates, enabling earlier failure detection, and improving uncertainty-guided agent execution across diverse agent tasks. These results demonstrate that explicitly modeling relational dependency is crucial to reliable UQ for long-horizon LLM agents, providing a practical foundation for trustworthy agent execution.

## 1. 核心问题与整体含义

- **研究背景**：LLM从被动生成器演变为自主智能体，在长时域任务中需要执行数十甚至上百步推理、工具调用与环境交互。此类系统的可靠性成为实际部署的关键障碍。

- **核心论点**：LLM智能体的不确定性应被视为一种**轨迹级属性**，其演化依赖于执行步骤之间的**关系结构**，而非一系列独立的置信度估计。将轨迹建模为线性序列不足以刻画真实的失效风险累积过程。

## 2. 方法论

### 2.1 核心思想
提出**RUPA（Relational Uncertainty Propagation for Agents）**框架，将执行轨迹建模为**有向关系图**，并在图上进行关系感知的不确定性传播，从而将历史风险与当前局部不确定性融合为轨迹级不确定性估计。

### 2.2 关系轨迹图构建
- **节点**：执行事件，包括用户指令、推理/动作、工具调用、环境观测。
- **边**（7种关系类型）：
  - Sequential（顺序承接）
  - Latest（最近环境/用户指令）
  - Repetition（重复行为）
  - Progression（推理延续）
  - Parallel（并行分支）
  - Feedback（环境反馈/失败信号）
  - Goal Alignment（目标对齐）
- 边的类型通过文本嵌入距离、词法线索（如"next"、"continue"、"error"等）等轻量确定性检测器确定，不使用未来结果或最终验证标签。

### 2.3 不确定性传播机制
- **局部不确定性 \(U_t\)**：推理节点用预测熵，环境节点用可观测交互信号（执行失败、空响应、冲突反馈）。
- **边权重**：
  \[
  w_{it} = \rho_{\tau_{it}} \tilde{r}_{it} \delta^{\text{age}(i,t)-1}
  \]
  其中 \(\rho\) 为关系类型可靠性系数（根据未标注轨迹统计方差计算），\(\tilde{r}\) 为关系强度，\(\delta\) 为时间衰减因子。
- **目标对齐分数**：
  \[
  Q_{it} = 1 - S(y_t, x)
  \]
  \(S\) 为相似度函数，衡量当前推理与原始任务目标的对齐程度。
- **图传播聚合**：
  \[
  G_t = \frac{\sum_{i \in N(t)} w_{it}(P_i + Q_{it})}{\sum_{i \in N(t)} w_{it} + \epsilon}
  \]
  \(P_i\) 为历史节点的已传播不确定性。
- **不确定性动量**：维护指数衰减的历史风险趋势：
  \[
  m_t = \frac{\sum_{k<t} \gamma^{t-k} P_k}{\sum_{k<t} \gamma^{t-k} + \epsilon},\quad H_t = \eta_g G_t + \eta_m m_t
  \]
- **最终风险估计**：
  \[
  R_t = \lambda_u U_t + \lambda_h H_t
  \]
  轨迹级不确定性通过对步级分数聚合得到。

### 2.4 算法流程
1. 执行轨迹归一化为文本状态（拼接助手消息、推理内容、工具调用签名、观测文本）；
2. 构建关系图（识别节点间7种关系边）；
3. 计算各节点局部不确定性；
4. 沿图传播不确定性（结合边权重、目标对齐、动量项）；
5. 融合局部+历史不确定性得到步级风险；
6. 聚合得到轨迹级置信度。

## 6. 主要结论与发现

1. **RUPA在所有基准和模型上一致取得最佳UQ性能**——例如在MiniMax-M2.7上平均AUROC从最强基线的0.694提升至0.718；在Qwen3.5-27B上从0.608提升至0.656。
2. **传统UQ方法在长时域智能体任务中几乎失效**——Entropy和Seq-prob的AUROC接近随机猜测水平（如Qwen3.5-27B上仅0.559和0.566）。
3. **线性序列建模不足以捕捉风险传播**——SAUP、Tracer、UProp等智能体感知方法虽优于传统方法，但仍无法充分刻画关系结构中的风险累积。
4. **RUPA支持更早的失败检测**——在仅观察轨迹前一小部分时，RUPA的优势已显著体现，说明传播的信号在早期即可预见未来失败。
5. **UQ可以转化为下游性能提升**——不确定性引导采样中，RUPA一致优于随机选择和baseline方法（如Qwen3.5-27B在Terminal-Bench-2上从0.105提升至0.213）。
6. **图信号提供了熵以外的互补信息**——在熵匹配的分箱中，RUPA在低熵区仍保持约0.85的AUROC，而传统方法接近0.5。
7. **消融证实图建模与传播机制均为关键组件**——移除图建模导致AUROC从0.718降至0.678；随机图拓扑产生类似降幅，证明性能来自有意义的关系结构而非额外图特征。

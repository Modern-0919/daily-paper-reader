## 摘要
基于大语言模型（LLM）的多智能体系统（MAS）常常表现出复杂的失败模式，这经常导致智能体产生错误的结果。这催生了智能体失败归因任务：给定一条失败的多智能体轨迹，识别出故障智能体及其对应的错误类型。现有方法主要依赖LLM进行失败归因，要么通过直接提示、在合成数据上进行微调，要么通过复杂的智能体流程。虽然这些方法有效，但由于长上下文处理、昂贵的后训练和手工工作流，它们带来了大量的计算开销。此外，经验证据表明，即使是当前最先进的模型在现有基准上的准确率也有限，这表明仅扩大模型规模是不够的。在本工作中，我们重新审视了这一任务，并质疑此类昂贵的生成式解决方案的必要性。我们引入了AFANet，一个轻量级基于图的框架，通过步骤级语义信号和智能体级关系对交互轨迹进行建模。我们表明，在参数显著更少且推理成本近乎为零的情况下，AFANet（i）在域内基准上匹配或超越了基于LLM的基线，包括微调模型；（ii）在不同GNN架构下保持稳健性能；（iii）通过在OOD基准上进行廉价的测试时自适应可以进一步提升。我们的结果表明，有效的智能体失败归因并不需要沉重的LLM推理，轻量级的结构化方法即可实现强性能。

## Abstract
Large language model (LLM)-based multi-agent systems (MAS) often exhibit complex failure modes, which frequently cause agents to produce incorrect outcomes. This motivates the task of Agent Failure Attribution: given a failed multi-agent trajectory, identify the faulty agents and their corresponding error types. Existing approaches predominantly rely on LLMs to perform failure attribution, either through direct prompting, fine-tuning on synthetic data or complex agentic pipelines. While effective, these methods incur substantial computational overhead due to long-context processing, expensive post-training and handcrafted workflows. Moreover, empirical evidence shows that even state-of-the-art models achieve limited accuracy on existing benchmarks, suggesting that scaling model size alone is insufficient. In this work, we revisit this task and question the necessity of such expensive generative solutions. We introduce AFANet, a lightweight graph-based framework that models interaction trajectories through step-level semantic signals and agent-level relationships. We show that with significantly fewer parameters and near-zero inference cost, AFANet (i) matches or outperforms LLM-based baselines, including fine-tuned models on in-domain benchmarks, (ii) maintains robust performance across different GNN architectures and (iii) can be further improved with inexpensive test-time adaptation on the OOD benchmark. Our results suggest that effective agent failure attribution does not require heavy LLM reasoning and a lightweight, structured approach can achieve strong performance.

## 2. 论文提出的方法论

### 2.1 核心思想

作者提出 **AFANet**，一个轻量级图神经网络框架，将失败轨迹建模为"轮次级对话图"（turn-level conversation graph），通过步骤级语义信号与智能体级结构关系捕捉失败传播的底层结构，以极低成本完成归因。

### 2.2 关键技术细节

**（1）对话图构建**
- **节点**：每个轨迹中的轮次（turn）作为一个节点，即每个 `(agent, content)` 对。
- **节点特征**（三部分拼接）：
  - **偏差特征（deviation features）**：基于每段对话内部计算的 TF-IDF 表示，经截断 SVD（r=16）降维后，计算多种一致性/偏差信号，包括：序列偏差（与前一轮的余弦距离）、自我不一致性（与同智能体历史行为的偏差）、对话共识偏差（与全局质心的偏差）、跨智能体偏差、智能体内部一致性、同智能体时间一致性、词汇稳定性、问题对齐度等；
  - **统计特征（statistical features）**：数字标记、词长均值/标准差（z归一化）、归一化位置、首/末轮指示、智能体参与比例、参与位置扩散度等非语义属性；
  - **稠密语义特征**：来自预训练句编码器（sentence-BERT，即 all-MiniLM-L6-v2）的嵌入。
- **边（两类）**：
  - **时序边**：相邻轮次之间的双向连接，保留对话顺序；
  - **同智能体边**：同一智能体产生的非相邻轮次之间的双向连接，捕捉跨轮次的长期一致性。

**（2）模型结构**
- **输入投影**：`h = LN(ReLU(W_in · x + b_in))`，将节点特征投影到隐藏空间；
- **GNN消息传递**：L层（默认2层，可选GCN/GAT/GraphSAGE），带残差连接，沿图结构传播邻居信息；
- **智能体级池化**：将属于同一智能体的轮次表示分别做均值池化和最大池化，再拼接；
- **预测头**：经过LayerNorm+ReLU的中间投影、瓶颈层（bottleneck dim=32）、Dropout，最终输出 K+1 类 logits（第0类为"正常"，其余为错误类型）。

**（3）训练目标**（双目标联合）
- **智能体级目标**：加权二分类交叉熵，判断每个智能体是否有故障（正类权重 = 干净样本数/故障样本数）；
- **错误级目标**：仅对故障智能体施加多类别交叉熵，分类具体错误类型；
- 总损失 = λ_agent·L_agent + λ_fm·L_fm。

**（4）推理**
- 基于验证集搜索阈值（代理级阈值 τ 和错误级阈值 τ_fm）进行阈值解码；或在OOD场景使用排序解码（该场景每段对话只有一个故障智能体）。

## 3. 实验设计

### 3.1 数据集与场景

| 数据集 | 用途 | 规模 |
|---|---|---|
| AEGIS-Bench（域内） | 训练/验证/测试 | 7146 / 1787 / 600 条轨迹 |
| Who&When（域外OOD） | 仅测试 | 184 条轨迹，每段恰好一个故障智能体 |

- 错误类型体系包含14类，分三组：规格问题（FM-1.x）、智能体间错位（FM-2.x）、任务验证失败（FM-3.x）。
- 评估指标：Agent级、Error级、Pair级（正确智能体-错误类型对）三个粒度的 Micro-F1 和 Macro-F1。

### 3.2 对比方法

- **预训练LLM**：Qwen2.5-7B/14B-Instruct、Qwen3-8B（非思考/思考模式）；
- **微调LLM**：上述模型的 SFT（+S）及后续 GRPO 强化学习变体（+S+G）；
- **专有LLM**：GPT-4.1、GPT-4o-mini、o3、Gemini-2.5-Flash/Pro、Claude-Sonnet-4；
- 作者自行复现的模型标注为 ∗∗，采用与 AEGIS 代码库一致的 All-at-Once 提示策略。

### 3.3 实验组数概览

- **主实验**：在2个数据集上对比约20种基线方法，报告6项指标；
- **骨干网络敏感性实验**：3种GNN架构（GCN/GAT/GraphSAGE）× 3种深度（1/2/3层）；
- **消融实验**：边类型消融（无边/仅同智能体边/仅时序边）、模型设计消融（去掉偏差/统计特征、去掉句嵌入、去掉GNN）；
- **测试时自适应（TTA）实验**：3种策略（Agent级熵最小化、Pair级熵最小化、故障智能体Pair级熵最小化）。

## 6. 论文的主要结论与发现

1. **效果可比或更优**：AFANet 在不依赖LLM推理的情况下，在 AEGIS-Bench 上取得 Pair 级指标第一（Pair μF1=17.42%），平均表现（24.82%）超越所有预训练、微调及专有 LLM 基线；在 Who&When 上的 Pair 级归因也保持领先，展现出对分布偏移的鲁棒性。
2. **效率优势巨大**：仅 65K 可训练参数、1.1 小时训练、近零推理成本，相比 7B/14B LLM 基线实现高达 70 倍训练加速和 300 倍推理加速。
3. **架构鲁棒**：在 GCN/GAT/GraphSAGE 及不同深度下性能稳定，说明有效性与具体GNN实现无关。
4. **组件均有贡献**：消融表明，图结构（时序边+同智能体边）、偏差/统计特征和句嵌入都对性能有实质贡献。
5. **测试时自适应有效**：在OOD数据上，基于熵最小化的轻量TTA（仅更新LayerNorm参数，30步梯度）可一致提升性能，其中 Pair-level 和 Pair-Faulty 策略增幅最明显。
6. **核心论断**：有效的智能体失败归因**不需要重型LLM推理**，轻量级、结构化的图建模方法即可实现强性能。

## 7. 优点（方法与实验设计的亮点）

- **视角新颖**：首次系统地质疑"失败归因必须依赖LLM推理"的主流范式，提出用轻量图网络替代重型生成模型，开辟了低成本归因的新方向。
- **特征工程精巧**：偏差特征的设计（序列偏差、自我不一致、跨智能体偏差、词汇稳定性等）将"异常检测"思想迁移到轨迹归因，有效捕捉了故障智能体的行为异常模式，且计算廉价。
- **图构建合理**：时序边+同智能体边的双类边设计，同时建模了错误传播的时序依赖与智能体行为一致性，对失败传播具有天然的表达能力。
- **效率极佳**：65K参数 vs 数十亿参数，训练/推理成本相差2-3个数量级，且性能不减，实用价值高。
- **鲁棒性验证充分**：跨GNN架构、层数、特征组件的多角度消融，证明了方法的稳定性和可迁移性。
- **TTA探索有启发性**：将测试时熵最小化引入OOD归因场景，提供了一种无需标注的廉价域适应手段。
- **复现意识好**：作者自行复现部分LLM基线（∗∗标记）并在统一设置下评估，降低了对原始基准报告结果的盲从风险。

## 8. 不足与局限

- **OOD泛化仍有挑战**：作者在附录E中坦承，在差异更大的多智能体设置上，分布偏移下的泛化仍是难题；当前域外测试集仅184条，验证强度有限。
- **推理能力天花板**：某些失败场景可能仍需要深层语义理解与长程推理，纯图模型存在上限；作者建议未来将图建模与LLM推理结合，也侧面承认了纯轻量方法的边界。
- **统计显著性缺失**：未报告误差棒或显著性检验，单次运行的性能差异可能不足以支撑所有结论。
- **实验覆盖有限**：仅2个 benchmark（且均来自作者合作/引用的社区数据集），缺少对更多MAS框架（不同智能体数量、不同任务类型、不同错误分布）的系统验证。
- **TF-IDF/SVD 特征的语料范围局限**：偏差特征基于单条对话内部统计，在轮次较少的轨迹上统计估计可能不稳定。
- **超参数敏感性未充分探索**：对隐藏维度、瓶颈维度、损失权重 λ 等超参数未做敏感性分析。
- **潜在偏差风险**：AFANet 的高效可能部分得益于 AEGIS-Bench 合成数据中错误模式的规律性，真实系统中的错误更具多样性和隐蔽性，其表现需谨慎外推。

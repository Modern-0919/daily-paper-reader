## 摘要
幻觉仍然是大型语言模型（LLM）在条件文本生成中可靠使用的主要障碍。现有方法主要评估整个生成文本的事实性，对于哪些输出跨度是幻觉的或它们如何与输入相关提供的洞察有限。我们引入了幻觉跨度检测与输入侧证据对齐的任务，该任务联合识别幻觉跨度并将输出标记与相应的输入证据对齐。我们的方法基于观察：忠实的输出标记可以从输入预测，而幻觉标记则不能。因此，我们训练一个基于编码器的模型，从输入表示中预测被掩蔽的输出标记，使用预测置信度进行幻觉检测，同时自然产生与输入的对齐。实验表明，所提出的方法有效检测幻觉跨度并识别有意义的输入侧证据。人工评估确认了预测对齐的质量。

## Abstract
Hallucinations remain a major obstacle to the reliable use of large language models (LLMs) in conditional text generation. Existing methods primarily assess the factuality of an entire generated text, providing limited insight into which output spans are hallucinated or how they relate to the input. We introduce the task of hallucination span detection with input-side evidence alignment, which jointly identifies hallucinated spans and aligns output tokens with the corresponding input evidence. Our approach is based on the observation that faithful output tokens are predictable from the input, whereas hallucinated tokens are not. We therefore train an encoder-based model to predict masked output tokens from the input representation, using prediction confidence for hallucination detection while naturally producing alignments to the input. Experiments show that the proposed method effectively detects hallucinated spans and identifies meaningful input-side evidence. Human evaluation confirms the quality of the predicted alignments.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- **观察**：忠实的输出 token 通常可以从输入文本中的支持性上下文**预测/恢复**出来；而幻觉 token 则**难以从输入中预测**。
- **策略**：将幻觉跨度检测转化为**“输入引导的掩码 token 预测”**任务。模型将被掩码的输出 token 从输入表示中恢复，恢复的**置信度**用于判定忠实/幻觉，恢复时**检索到的输入 token 即为证据对齐**。

### 关键技术细节

1. **训练阶段：span 级掩码预测**
   - **Span 分割**：利用语义角色标注（SRL, Semantic Role Labeling）将输出文本切分为语义完整的 spans（如谓词+论点）。相邻谓词 span 合并以处理被动/进行时结构。
   - **掩码与编码**：被掩码的 span 替换为两个连续的特殊 token `<mask><mask>`；输入文本与掩码后的输出文本拼接后由编码器编码。
   - **置信度计算**：对于输出 span \(s\) 和输入位置 \(i \le j\)，定义：
     \[
     c(s, i, j) = \text{sim}(m_s, d_i) + \text{sim}(m_e, d_j)
     \]
     其中 \(m_s, m_e\) 是两个掩码 token 的嵌入，\(d_i, d_j\) 是输入 token 的隐藏表示，sim 为余弦相似度。最终取最大置信度作为该 span 的预测得分：
     \[
     c^{\max}_s = \max_{(k, \ell)} c(s, k, \ell)
     \]
   - **损失函数**：设计了分段损失：
     \[
     L = \frac{1}{M}\sum_{i \in M} f(s_i)
     \]
     其中
     \[
     f(s_i) =
     \begin{cases}
     \max(0, c^{\max}_{s_i} - \gamma_h), & \text{幻觉 span} \\
     \max(0, \gamma_f - c^{\max}_{s_i}), & \text{忠实 span}
     \end{cases}
     \]
     \(\gamma_h\) 和 \(\gamma_f\) 分别控制幻觉/忠实的置信度上下界；对困难样本额外加权（\(w=2.0\)）。
   - 训练中优先采样幻觉 span，以缓解类别不平衡。

2. **推理阶段：token 级预测**
   - 每个输出 token 单独掩码（单 `<mask>`），与输入拼接编码后计算置信度；
   - 按阈值 \(\lambda_h\)（实验中为 0.68）判定该 token 是否幻觉；
   - 子词聚合到词级，只有全部子词被判为幻觉时该词才被判为幻觉；
   - 置信度最高的输入 token 作为证据对齐。

### 与 NPM 的关系
- 方法借鉴了**非参数掩码语言模型（NPM）**的思想，通过检索输入中表示最相似的 token 来恢复掩码 token，而非直接从词表中生成。

## 6. 论文的主要结论与发现

1. **幻觉检测能力**：
   - 提出的方法在 **QA 和 Summarization 任务上取得了最高的召回率**（QA: 82.7%；Sum: 38.0%），适合“不可漏检幻觉”的应用场景；
   - 在 F1 分数上低于 LettuceDetect（QA）和 Llama-SFT（Summarization），说明精确率和召回率之间存在权衡。
2. **输入侧证据对齐**：
   - 人工评估显示，对忠实词和 baseless 幻觉词，提出的方法能够提供**有意义的输入证据**（平均评分约 2 分，即“相关句子中的证据”）。
   - 对齐虽常常不能精确匹配原词（score 3），但多数预测为语义相关的输入词（score 2），仍可解释生成内容的来源。
3. **Conflic（矛盾）幻觉是难点**：
   - 对 conflict 幻觉的召回率很低（QA: 14.0%；Sum: 16.6%），而 baseless 幻觉的召回率很高（QA: 87.6%~91.2%；Sum: 37.7%~50.1%）。
   - 原因：conflict 幻觉在输入中存在高度相关的对应文本，导致其表示与输入 token 相似度高，混淆了置信度评估。
4. **分布分离效果**：
   - 微调后忠实词与幻觉词的置信度分布明显分离，但幻觉词的分布呈**双峰**（低峰对应 baseless，高峰对应 conflict），说明不同类型幻觉的难度差异显著。
5. **基线对比**：
   - OTAlign 在句子集对齐场景下表现不佳，说明现有词对齐方法难以直接迁移到长文本输入-输出对齐任务。

## 7. 优点

- **任务创新**：首次联合“幻觉 span 检测”和“输入侧证据对齐”，填补了现有方法的空白。
- **方法设计巧妙**：
  - 无需人工对齐标注，仅靠远距离监督即可训练；
  - 单一模型同时输出幻觉判断+证据对齐，无额外模块；
  - 基于轻量级编码器（0.4B），推理成本远低于 decoder 大模型（如 Llama-8B）。
- **训练策略合理**：
  - 使用 SRL 语义跨度进行掩码，优于随机 token 掩码；
  - 损失函数显式区分忠实/幻觉跨度，并对困难样本加权；
  - 训练中优先采样幻觉 span，缓解类别不平衡。
- **评估全面**：自动评估 + 人工评估 + 案例分析 + 按幻觉类型的细粒度分析，提供了对方法优缺点的立体理解。
- **可解释性提升**：生成的证据对齐可直接辅助用户在长文档中追踪生成内容的来源，具有实际应用价值。

## 8. 不足与局限

- **推理计算开销大**：
  - 推理时每个输出 token 需要单独掩码并重新编码输入+输出，计算复杂度随输出长度线性增长，对长文本不友好。
- **conflict 幻觉检测能力弱**：
  - 对含有高度相关输入证据的矛盾型幻觉基本失效（召回率极低），而这恰恰是验证中最危险的幻觉类型。
- **实验覆盖有限**：
  - 仅使用 RAGTruth（QA、摘要），未在数据-文本、多语言、多领域或多种 LLM 生成文本上验证；
  - 未报告在细粒度跨度的精确度/F1（仅字符级指标），且无消融实验。
- **对齐质量上限受限于预训练模型**：
  - 因为训练目标不是直接监督 token 对齐，恢复精确证据的能力依赖于 ModernBERT 的预训练知识，因此常产生语义相关但非精确匹配的对齐。
- **人工评估的主观性强**：
  - 仅由作者本人评估，缺乏独立评估者及一致性统计，评分标准（如 score 2/3 的区分）可能存在主观偏差。
- **阈值选择**：
  - 依赖一个固定的阈值 \(\lambda_h\)（0.68），不同数据分布下可能需要重新调优，鲁棒性未验证。
- **对 baseless 幻觉的高召回可能伴随高误报**：在追求高召回的同时，精确率较低（QA 40.9%），可能在实际使用时带来过多的误报干扰。

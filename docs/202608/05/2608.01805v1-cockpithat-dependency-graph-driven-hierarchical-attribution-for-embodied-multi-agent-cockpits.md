## 摘要
LLM多智能体系统存在正确性崩溃问题，即高任务级准确率掩盖了严重的过程级失败。这在汽车驾驶舱等安全关键的具身场景中尤为危险，因为词汇上正确的表述可能触发危险的实际操作。现有归因方法仅依赖文本痕迹，缺乏依赖结构、多渠道证据和安全感知评估。我们提出CockpitHAT，一种层次化归因框架，通过交互DAG的依赖距离阈值替代位置窗口，通过具身适配器整合多渠道证据，并在置信度加权分析师共识中对高风险失败施加安全提升。我们进一步发布了CockpitBench，一个包含212条标注失败轨迹的基准，涵盖对话、车辆状态、环境和记忆通道，每条轨迹均通过三位专家共识标注ISO 26262 ASIL严重性。在公开的Who&When基准上，CockpitHAT在手工构建子集上达到77.9% / 37.8%的智能体级/步骤精确准确率，在算法生成子集上达到86.5% / 46.0%，比仅文本的SOTA ECHO高出最多17.6 / 16.7个百分点。在CockpitBench上，它达到78.3%的智能体级和38.2%的步骤精确准确率。这些结果确立了依赖感知、多渠道、风险校准的归因作为现实世界具身LLM多智能体系统中可靠故障诊断的有效范式。

## Abstract
LLM multi-agent systems suffer from Correctness Collapse, where high task-level accuracy conceals severe process-level failures. This is especially hazardous in safety-critical embodied settings such as automotive cockpits, where lexically correct utterances may trigger dangerous physical operations. Existing attribution methods rely on text traces alone, missing dependency structure, multi-channel evidence, and safety-aware evaluation. We introduce CockpitHAT, a hierarchical attribution framework that replaces positional windows with dependency-distance thresholds from interaction DAGs, integrates multi-channel evidence via an embodied adapter, and applies a safety-uplift to high-risk failures during confidence-weighted analyst consensus. We further release CockpitBench, a benchmark of 212 annotated failure traces spanning dialogue, vehicle-state, environmental, and memory channels, each labeled with ISO 26262 ASIL severity via three-expert consensus. On the public Who&When benchmark, CockpitHAT achieves agent-level / step-exact accuracies of 77.9% / 37.8% on the Hand-Crafted split and 86.5% / 46.0% on the Algorithm-Generated split, surpassing the text-only SOTA ECHO by up to 17.6 / 16.7 points. On CockpitBench, it attains 78.3% agent-level and 38.2% step-exact accuracy. These results establish dependency-aware, multi-channel, risk-calibrated attribution as an effective paradigm for reliable failure diagnosis in real-world embodied LLM multi-agent systems.

### 2. 论文提出的方法论

论文提出 **CockpitHAT**，由四个主要模块组成，核心思想是以**交互DAG的依赖距离**替代传统的位置窗口，并从多通道证据与风控层面增强归因。

- **依赖图构建（Dependency Graph Construction）**：
  - 将轨迹 `T = ⟨s1, ..., sn⟩` 映射为有向无环图 `G = (V, E)`，每个节点为一步 `si`，包含角色、子模式、文本或结构化工具调用。
  - 通过四种操作信号触发边：引用依赖、计划依赖、工具依赖、控制依赖；
  - 定义**依赖距离** `dd(vi, vj)` 为无向图中的最短路径长度；
  - 边归纳采用局部模式匹配 + 实体链接，最坏复杂度 O(n²)，实际常用 O(n)，图为确定性且可复用。

- **依赖距离层次切片（Dependency-Distance Hierarchical Slicing）**：
  - 以依赖距离（而非位置偏移）划分四个上下文层级：
    - L1（Immediate）：`{vi} ∪ N1(vi)`，保留完整推理链与工具对；
    - L2（Local）：`N2(vi)`，压缩为关键动作、承诺与结论；
    - L3（Distant）：`N3 ∪ N4`，每步最多20词摘要；
    - L4（Global）：`dd ≥ 5` 的节点用稀疏里程碑表示；
  - 通过依赖距离切片，错误传播沿依赖边传导时可被精准追踪，避免了位置相邻但依赖无关步骤的干扰。

- **具身通道适配器（Embodied Channel Adapter, ECA）**：
  - 仅当轨迹含具身字段（环境、车辆状态、记忆）时启用；
  - 执行一次 **salience scanning**，使用轻量LLM对每步标注 `(i, τi, pi)`，其中 `τi` 对应四种具身失败类别：交互风险、环境误接地、安全违规、跨域污染；
  - **通道感知提升**：将带标志的节点上移一层；`SAFETY_VIOLATION` 强制移入 L1；
  - 根据标记类型附加对应的通道证据（如安全违规附加车辆状态与环境数据）。

- **安全提升的目标共识分析（Safety-Uplifted Objective Consensus Analysis）**：
  - 每个轨迹部署 K=4 名分析师：1名强制安全分析师 + 3名从六人设池中随机抽取的通用分析师；
  - 每个分析师输出假设 `hk = (ŝk, âk, τ̂k, η̂k)` 和置信度 `ck`；
  - **两阶段分解共识**：
    - Stage 1：基于 `η* = max⪰{η̂k | ck ≥ δconf}` 获取最大严重性先验；
    - Stage 2：计算非对称安全提升权重 `Ω(k, η*)`，采用指数调度并设有封顶系数防止单一分析师主导，最终对代理人、步骤、失败类别分别进行加权边际投票；
  - 分歧解决协议：当最弱边际分数低于 ASIL 校准阈值时启动，分析师须引用明确证据辩护，平局机制偏向有具体证据支持的假设。

### 7. 优点

- **方法论创新**：以交互DAG的依赖距离（而非位置窗口）作为层次切片依据，结构性更强并减少了无关邻近步骤干扰；
- **首次引入具身通道适配器（ECA）**：对文本通道之外的车辆状态、环境与记忆证据进行标注、筛选、通道提升，弥补纯文本归因的结构盲区；
- **安全校准的共识机制**：
  - 通过两阶段解耦（先推断最大ASIL严重性，再做归因聚合）避免了严重性与可信度的自增强循环；
  - 安全分析师享有指数式提升权重（ASIL-D时≈2.16），并设封顶防主导；
  - 针对 ASIL 校准阈值的分歧解决机制要求证据链支持，提升可解释性。
- **基准贡献**：CockpitBench 提供带有三通道证据与ASIL标签的数据集，并保留 contested 轨迹，弥补了现有基准的空白；
- **实验设计较完整**：包含跨数据集、消融、骨干模型消融、效率、显著性检验、标注质量多维评估，体现较强的工程完备性；
- 代码与数据将公开，促进可复现性。

### 8. 不足与局限

- **依赖图只能捕捉显式依赖**：基于引用、计划、工具、控制四种信号，对隐式依赖（如共享领域知识、模糊开放式场景背后的隐性关系）可能失效；
- **超参数需人工调整**：安全提升参数（λ=0.5, β=0.4, κ=1.0）、分析师面板配置只针对汽车驾驶舱领域校准，对其他安全关键领域无法直接迁移，且无自适应能力；
- **仅支持事后诊断**：CockpitHAT无法实现实时错误检测与缓解，对安全关键系统的事前预防作用有限；
- **步骤级归因仍偏低**：CockpitBench 上步骤级精确率仅38.2%，距离实际部署要求尚有较大差距；虽然对规划失败类等给出客观剖析，但步骤级定位仍是悬而未决的核心挑战；
- **部分模块依赖LLM不透明输出**（如ECA的自报告显著性分数 `pi` 属于模型主观置信度）与实体链接质量，对底层模型敏感；
- **评估集中于少数内部模型（Doubao系列）**，对国际主流模型的可泛化性尚不确定；
- 论文提及将发布代码与数据，但未提供外部复现验证结果；
- 基准数据来自仿真器及适配场景，真实车载环境中的迁移性能仍需进一步探索。

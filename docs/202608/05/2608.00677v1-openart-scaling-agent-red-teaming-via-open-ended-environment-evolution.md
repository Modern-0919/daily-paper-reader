## 摘要
AI智能体在持久化环境中运行，其中早期的状态变化可能影响未来很长时间内的决策。与传统语言模型交互不同，智能体的行为通过共享状态进行中介，该状态在长周期工作流中被反复修改和重用。当前的安全基准测试通常无法捕捉这些累积风险，因为它们侧重于短期、静态的任务。为解决这些局限性，我们引入了OpenART，一个通过环境演化进行可扩展智能体红队测试的开放式竞技场。OpenART提供了跨越50个领域的超过10,000个经过验证的有状态场景，这些场景来源于超过500,000个工具和技能的池子。这些任务需要中位数97次工具调用，并支持对75种不同的智能体模型配置进行统一评估。为了系统地探索这些不断演化的攻击面，我们提出了进化马尔可夫超图攻击（EMHA）。EMHA是一种黑盒策略，通过协调授权的状态转换来执行反馈驱动的环境演化，无需参数更新。在整个评估过程中，任务目标保持不变，仅环境状态发生变化。在所有配置中，EMHA实现了85.0%的汇总攻击成功率（ASR）。其相对于仅指令演化的优势从简单环境中的约2%增加到最复杂环境中的超过17%，表明随着任务复杂性的增长，环境演化越来越能暴露安全失败。此外，我们的分析显示，智能体的特定运行时实现解释了超出底层模型能力之外的大部分安全差异。这些结果确立了OpenART作为在复杂、演化环境中研究智能体安全的可扩展基础。

## Abstract
AI agents operate in persistent environments where early state changes can influence decisions far into the future. Unlike conventional language-model interactions, agent behavior is mediated through a shared state that is repeatedly modified and reused across long-horizon workflows. Current safety benchmarks often fail to capture these cumulative risks because they focus on short, static tasks. To address these limitations, we introduce OpenART, an open-ended arena for scalable agent red teaming through environment evolution. OpenART provides over 10,000 validated stateful scenarios across 50 domains, drawing from a pool of more than 500,000 tools and skills. These tasks require a median of 97 tool calls and enable unified evaluation across 75 different agent-model configurations. To systematically explore these evolving attack surfaces, we propose the Evolutionary Markov Hypergraph Attack (EMHA). EMHA is a black-box policy that performs feedback-driven environment evolution by coordinating authorized state transitions without requiring parameter updates. Throughout the evaluation, task objectives remain fixed while only the environment state changes. Across all configurations, EMHA achieves a pooled Attack Success Rate (ASR) of 85.0%. Its advantage over instruction-only evolution increases from approximately 2% on simple environments to over 17% on the most complex ones, demonstrating that environment evolution increasingly exposes safety failures as task complexity grows. Furthermore, our analysis shows that the specific runtime implementation of an agent explains a significant portion of safety variation beyond the underlying model's capabilities. These results establish OpenART as a scalable foundation for studying agent safety in complex, evolving environments.

## 1. 核心问题与整体含义

- **研究背景**：AI 智能体在持久化环境中运行，其行为通过共享状态被反复读写和修改，早期状态变化可能在未来很远的工作流节点才显现危害。现有多数安全基准（如 InjecAgent、AgentDojo、ToolEmu 等）局限于短时、静态或可重置环境的单轮评估，难以刻画长周期工作流中的累积风险、延迟传播与演化式安全失效。
- **核心问题**：如何构建一个可扩展、统一、可比较的评估框架，用于系统研究智能体在**不断演化的持久环境**中的安全行为，而不是仅评估孤立提示或单步动作。
- **整体含义**：OpenART 将“可执行环境”而非单个提示作为红队测试的基本单元，通过受控环境演化来暴露静态基准遗漏的长程风险，并揭示智能体运行时实现本身对安全的显著影响。

## 2. 方法论

- **核心思想**：在保持良性任务目标和隐藏安全契约不变的前提下，只演化目标智能体可见的环境状态，通过反馈驱动的搜索逐步提高同一场景的攻击难度。
- **OpenART 三阶段框架**：
  1. **长周期场景构建**：基于 O*NET 领域分类与 SkillNet 收集的 50 万+ 工具/MCP/技能，由规划器生成由依赖图（工作流 DAG）约束的可执行场景；每个场景包含良性任务、初始环境、隐藏安全契约和确定性评估器，并通过自动化探针与人工审计验证。
  2. **跨 Agent 运行时投影**：场景保持目标无关，通过轻量适配器将同一任务、评估器与安全契约投影到不同 Agent 原生接口（如指令文件、Skill 目录、MCP 工具等），支持 8 种目标可见攻击向量（工作区、指令、技能、工具、MCP、短期记忆、计划状态、长期记忆）。
  3. **受控环境演化**：红队策略仅修改被授权且目标可见的状态，任务目标与评估器保持不变；目标执行后产生轨迹、状态和评估反馈，反馈用于指导下一轮演化。
- **EMHA（进化马尔可夫超图攻击）**：
  - 将被时间延伸的环境演化建模为超图遍历：顶点是攻击子目标，超边连接前置子目标与后继子目标，每条超边关联一个突变模板。
  - 每轮从候选图中采样路径，再用冻结的 LLM 解码为具体的环境更新；模型参数全程不变（θₜ₊₁ = θₜ），只通过外部攻击者状态实现上下文内适应。
  - 采用软路径策略（softmax over Q 值）平衡探索与利用；反馈通过延迟奖励分配更新超图转移的价值，以最大化预算内最佳评估分数。
  - 使用 MAP-Elites 类质量多样性归档保留最优攻击样本，并通过图编辑算子生成后代，实现黑盒进化搜索。
- **攻击判据**：严格攻击成功率（Strict ASR）要求确定性评估器与 GLM-5.2 判断器同时判定攻击成功，不一致即视为失败。

## 3. 实验设计

- **数据集 / 场景**：OpenART 自建竞技场，包含 10K 个已验证场景、50 个领域、500K+ 能力（工具/MCP/技能）；任务中位数为 97 次工具调用、依赖深度 32、并行宽度 12.5、状态对象 96.5、文件格式 7.5，显著高于现有基准（如 DTap 中位数 15 次调用）。

## 6. 主要结论与发现

- EMHA 在 75 种配置上达到 **85.0% 的汇总严格攻击成功率**。
- 环境演化相对于纯指令演化的优势随复杂度增加而显著扩大：在简单环境中仅提升 1.8–2.7%，在依赖深度、工具调用数最高的复杂场景中提升达 17.2–17.6%；在文件格式多样性和并行宽度上也持续为正但渐趋饱和。
- 在控制基础模型和良性任务完成率后，加入目标智能体身份可额外解释 **7.6% 的 ASR 变异**（从 91.3% 增至 98.9%），说明 Agent 运行时实现本身显著影响安全性。
- 长期安全漂移普遍存在：环境变化被首次消费时仅位于执行进度的 23%，而首次不安全输出出现在 64%，中位传播距离为 37 个动作，中位潜伏期达 41%。
- 反复出现三类脆弱性：
  1. 陈旧假设未被失效（计划-引用漂移、能力重绑定、检查点过期）；
  2. 安全决策被传播而非重新计算（如 schema 完整性被视为安全性证据）；
  3. 风险在长工作流中组合涌现（多个独立良性状态变化组合成泄露）。

## 7. 优点

- **大规模与高覆盖**：10K 场景、50 领域、500K+ 能力库、75 配置，远超同类基准。
- **统一可比较**：目标无关场景表示 + 轻量适配器，实现跨 Agent、模型、接口和攻击向量的受控比较。
- **以环境为评估单元**：将红队测试从提示优化扩展到状态演化，能暴露静态基准无法发现的延迟与组合型安全失败。
- **黑盒无参数更新**：EMHA 仅依赖评估反馈和外部攻击者状态，模型参数冻结，适配实际部署中的不可修改模型。
- **策略无关框架**：OpenART 的环境演化接口支持任意黑盒搜索策略，不仅限于 EMHA。
- **严格的攻击判定**：确定性评估器 + 独立 LLM 判断器双重确认，减少误报。
- **深入的可解释分析**：通过传播距离、复杂度分组与案例追踪，揭示了安全失效的机制性规律。

## 8. 不足与局限

- **算力与成本未披露**：缺少 GPU、训练/推理开销等信息，难以评估可复现性与实际使用成本。
- **Agent 覆盖偏重代码/命令行工具**：15 个目标智能体大多为代码代理，对更广泛的一般任务代理（如浏览器代理、多模态代理）覆盖不足。

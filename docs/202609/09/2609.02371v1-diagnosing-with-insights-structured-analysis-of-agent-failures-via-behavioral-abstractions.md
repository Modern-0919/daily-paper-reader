## 摘要
随着LLM智能体的激增，理解和诊断智能体失败的能力对于实现卓越的效果和可信度至关重要。由于智能体失败通常通过漫长而复杂的轨迹显现，手动在干草堆中寻找针是难以实现的。然而，针对软件缺陷的传统诊断技术难以应对LLM智能体的失败，而完全依赖LLM作为判断者则会产生不可靠的诊断结果。为克服这些挑战，本文提出AGENTSCOPE，一种用于智能体失败模式诊断的新型神经符号方法。AGENTSCOPE的关键原则是基于轨迹将智能体行为抽象为结构化表示。此外，AGENTSCOPE引入神经不变量的概念来指定智能体行为属性。AGENTSCOPE利用基于LLM的推理，在结构化表示之上针对神经不变量进行推理，以精确定位轨迹中的失败步骤及其类型。我们在公开可用的智能体失败数据集（Who&When）以及我们创建的更全面的数据集（AgentErrata）上展示了AGENTSCOPE的有效性，在这些数据集上，AGENTSCOPE在故障定位和归因准确率方面显著优于当前最先进的方法。我们的工作表明，将结构化抽象与基于LLM的推理相结合，能够实现有效、可靠且可解释的智能体失败诊断。

## Abstract
With the proliferation of LLM agents, the ability to understand and diagnose failures in agents is essential to achieving superior effectiveness and trustworthiness. As agent failures often manifest via long and complex trajectories, manually finding the needles in the haystack is untenable. However, traditional diagnosis techniques for software bugs can hardly address LLM agent failures, while completely relying on LLMs as the judge yields unreliable diagnosis results. To overcome these challenges, this paper presents AGENTSCOPE, a new neuro-symbolic approach for agent failure mode diagnosis. The key principle of AGENTSCOPE is to abstract agent behavior, based on its trajectories, into structured representations. Furthermore, AGENTSCOPE introduces the concept of neural invariants to specify agent behavior properties. AGENTSCOPE leverages LLM-guided reasoning atop the structured representation against neural invariants to pinpoint both the failure step and its type in the trajectory. We show the effectiveness of AGENTSCOPE on publicly available agent failure datasets (Who&When) and a more comprehensive dataset created by us (AgentErrata), where AGENTSCOPE significantly outperforms the current state of the art in fault localization and attribution accuracy. Our work shows that integrating structured abstractions with LLM-guided reasoning enables effective, reliable, and interpretable diagnosis for agent failures.

## 2. 论文提出的方法论

### 2.1 核心思想

- 论文提出一种 **神经符号（neuro-symbolic）方法**：以符号化的结构化抽象规定智能体行为语义，以神经网络（LLM）实现语义化判断（即“神经函数”），二者结合用于验证行为属性并定位失败。
- 核心概念包括两个：
  - **行为抽象（Behavioral Abstraction）**：把轨迹转为 **Reasoning-Action Graph（ReAG）**。
  - **神经不变量（Neural Invariants）**：用于刻画智能体行为正确性或失败模式属性的可验证条件。

### 2.2 关键表示：ReAG

- ReAG 定义为有向无环图 \(G = \{V, E\}\)：
  - 顶点 \(v_i = \langle id_i, r_i, c_i, I_i\rangle\)，其中 \(id\) 为步骤标识、\(r\) 为执行角色、\(c\) 为操作内容、\(I_i\) 为**中间语义表示（ISR）**。
  - ISR 由三元组 \(I_i = (C_i, R_i, S_i)\) 构成：
    - \(C_i\)：意图与上下文成分（任务目标、指令、步骤目的）；
    - \(R_i\)：推理与动作成分（决策摘要、实际动作、工具调用与输出）；
    - \(S_i\)：信号与验证成分（内部知识使用、置信度、终止信号）。
  - 边 \(E\) 表示步骤间的控制/数据依赖。
- 通过 API 调用、工具交互、系统日志的插桩和语义解析，将无结构日志转为带注释的 ReAG，供后续分析使用。

### 2.3 神经不变量与失败模式映射

- **神经不变量**的独特之处在于：传统程序不变量依赖纯符号条件，而 AGENTSCOPE 的神经不变量允许通过“神经函数”进行语义条件判断；每个神经函数本质是一个结构化 prompt 的 LLM 调用。
- 论文建立了 10 种失败模式的三维分类（推理、控制流、动作）：Wrong Context、Instruction Unfollowing、Insufficient Context、Context Miss、Termination Miss、Premature Termination、Step Loop、Action Mismatch、Invocation Issue、Execution Failure。
- 每种失败模式都被形式化定义为某个**不变量违背**。例如：
  - Action Mismatch 的违背形式为：
    \[
    iv_{mismatch} ::= \exists n_t \in N_{action}, n_{t-1} \in N_{reason}: \neg aligned(purpose_{t-1}, action_t, tool\_name_t, tool\_args_t)
    \]
  - 其中 \(aligned(\cdot)\) 为二分类神经函数，判断“意图→动作→工具”是否一致。
- 附录 A 给出了其余 9 种失败模式对应的不变量公式；不变量集合可随新失败模式扩展。

### 2.4 三阶段实现流程

- **阶段一：ReAG 构建**。将原始运行轨迹转换为统一、注释化、语义对齐的图结构；每个步骤补充角色、指令、动作、缺失信息信号、步骤目的等语义字段。这样可以减少 LLM 直接读原始文本带来的步骤错位、位置敏感和上下文遗忘问题。
- **阶段二：失败模式检测**。在 ReAG 上逐个进行各神经不变量检查；每个检查只关注相关步骤和局部上下文，而不是全轨迹。结果是**多个候选失败及证据**，而非立即输出单个结论，从而避免过早判断并保持可审计性。
- **阶段三：决定性错误判断**。利用整条轨迹和可选任务上下文，从候选中选出**最能解释最终劣化结果的“决定性（root-cause）”失败**；该失败不一定是第一个异常，而是下游影响最强的步骤。
- 这种“先结构化→局部验证→全局筛选”的设计降低了 LLM 长上下文、位置敏感等固有局限，并提高了结果的可解释性和可扩展性。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **Who&When**（公开）：用于失败定位，包含 184 条人工标注轨迹，分为两个子集：
  - Algo-Generated：126 条；
  - Hand-Crafted：58 条。
  - 局限：只标注失败步骤，未明确标注失败类型；标注的是“最早出现错误的步骤”，可能与最终决定性错误不一致。
- **AgentErrata**（作者新建）：为避免 Who&When 的标注偏差并补充失败类型标签，作者通过“失败分类指导的故障注入”构建。
  - 从 Agent 框架（OpenManus、OWL、Mini SWE Agent）和任务基准（BrowseComp、SWE-Bench Lite、WebArena）中采集轨迹，先筛选出成功完成任务且无污染的轨迹，再注入失败使任务最终失败，同时保持语义连贯。
  - 失败注入覆盖 10 种失败模式，近似均匀；所有轨迹经过人工验证。
  - 当前版本包含 **303 条高质量轨迹**。
- 未采用 MAST 数据集，因为它只标注整体失败类型，缺少具体步骤和原因，不便评估根因定位。

### 3.2 评估指标

- **SLA (Step-Level Accuracy)**：正确预测根因步骤的比例。
- **SLAT (Step-Level Accuracy with tolerance)**：预测步骤在真实步骤 ±δ（δ=0, 1, 3）范围内即算正确。
- **CA (Classification Accuracy)**：预测的失败模式集合中任一命中真实失败模式即正确。
- 未采用原作者使用的 Agent-Level Accuracy（ALA），因其不能反映具体失败步骤、角色分布偏斜，易高估。

### 3.3 对比方法与模型

- 对比基准（来自 Zhang et al. 2025c）：
  - **W&W All-at-once**：将整条轨迹一次性交给 LLM 判断；
  - **W&W Step-by-step**：按顺序逐步分析，每一步结合之前的前缀上下文判断是否异常；
  - 另在归因实验中加入了引入失败分类信息的 **LLM-as-Judge** 基线。
- 背骨模型：GPT-4o (2024-11-20)、GPT-5.1 (2025-11-13)、DeepSeek-V3.2，均经 Azure AI Foundry 部署，temperature=0.01、max_tokens=4096，其他参数默认。
- 实验设置还包含“提供任务 ground-truth 解决方案（w/ Solution）”与“不提供（w/o Solution）”两种条件。

## 6. 论文的主要结论与发现

- **AGENTSCOPE 在失败定位与归因上显著优于两种基线**：
  - 在 AgentErrata 上，w/o Solution 且 GPT-5.1 时，SLA 达 31.35%（基线仅 1.32%–3.30%）；SLAT ±3 时达 54.13%（基线 13.20%–18.81%）。
  - 在 Who&When 两子集上也有提升，但优势在 GPT-5.1 下略有缩小，作者解释为数据集标注策略差异（标注“最早错误”而非“决定性错误”）。
- **归因（CA）也得到明显改善**：GPT-5.1 下 CA 从基线的 18.15% 提升到 45.87%，且不依赖是否提供 ground-truth solution，说明改进源自结构化解耦，而非信息泄漏。
- **模型能力与诊断准确率并不单调相关**：GPT-5.1 作为生成模型可能更强，但在诊断任务上并未一致优于 GPT-4o 或 DeepSeek-V3.2；AGENTSCOPE 相比基线在不同背骨模型间的方差更小，说明结构化流程起到了“去偏”作用。
- **失败定位不是简单的逐步骤异常检测**，而是需要在轨迹层面区分“最早错误”“下游症状”“决定性根因”；AGENTSCOPE 的三阶段流程通过保留候选、再全局选择来处理这一问题。
- **运行时开销可接受但仍有优化空间**：单条轨迹约 25–750 秒；Step Loop 检测成本最高（多窗口两两比较，LLM 调用随窗口数平方增长）。论文指出可通过并行化、按提示词长度打包、共享前缀缓存等降低开销。

## 7. 优点

- **概念新颖**：提出“神经不变量”，将智能体失败模式形式化为可由 LLM 判断语义条件的不变量违背，架起了符号验证与神经网络语义推理之间的桥梁。
- **结构化带来可解释性**：ReAG+ISR 提供了清晰的步骤对齐和语义摘要；最终判断可回溯到具体不变量违规和局部证据，不是黑盒评分。
- **三阶段流程设计合理**：先构建结构化表示 → 独立局部检查 → 全局决定性筛选，能降低 LLM 长上下文和位置敏感问题，避免过早错误提交，并支持不同用户目标（找最早错误、找不可恢复点等）的可扩展选择策略。
- **数据贡献**：构建了带步骤级和类型级标注的 AgentErrata，填补了 Where&Where 缺少失败类型/决定性错误标注的空白；通过故障分类指导注入保证类型分布，且有人工筛选。
- **评估较扎实**：在多个数据集、多种模型、多种容差和有无 solution 条件下进行对比；运行时分析也给出了调用数与耗时的分布，而非只报精度。
- **实用性**：框架可采用任意通用 LLM 作为神经函数，不依赖微调；可集成现代 agent 框架，支持在线/离线及单/多智能体轨迹。

- **资源与效率信息不足**：没有给出 GPU/调用量/费用等可复现资源消耗；运行时分析仅基于 20

条轨迹，样本量小，且未报告不同轨迹长度、不同失败模式下的成本差异；未讨论缓存/并行化的实测改进效果。

- **对“失败模式/根因”定义缺乏形式化公理**：论文虽然列出10种失败模式并通过不变量定义，但未证明这些模式是完备且互斥的；在自然轨迹中一个步骤可能涉及多种失败（例如动作不匹配与调用问题同时发生），神经不变量检查返回布尔值可能忽略多因交织或严重程度。
- **依赖LLM语义判断的可靠性上限**：神经函数本身仍然是LLM prompt，可能继承幻觉、过度置信或位置偏差；论文没有对神经函数本身进行校准、错误率分析或失败模式敏感性分析。
- **泛化性未充分验证**：任务类型限于问答/软件工程/网页浏览等文本场景，未覆盖多模态、具身、规划复杂且交互频度高的任务；多智能体场景虽然提到可扩展，但实验评估仍以单智能体轨迹为主。
- **可复现性**：模型版本为“GPT-5.1 (2025-11-13)”等，可能随API更新而变化；AgentErrata 数据集没有给出开放下载地址/许可证等细节。

## 9. 可能的改进方向与未来工作

- 可考虑引入“根因准则”的形式化公理，例如根据后向切片（backward slicing）、支配关系（dominance）或“最小割集”来精确定义决定性错误，而不是当前的启发式全轨迹再判断。
- 将神经不变量扩展为连续/分级值（而不是二元违背），并对不同证据赋予权重，从而处理多种并发失败模式；或者采用结构化概率模型（如因果贝叶斯网络）将不变量检查结果作为证据进行概率推断。
- 对每个神经函数进行独立评估与置信度校准，必要时结合多数投票、自我一致性（self-consistency）或思维图谱；也可以考虑在步骤间引入状态差异（diff）来辅助定位。
- 增加真正的消融实验，例如：
  - 去掉ReAG而直接使用神经不变量+原轨迹；
  - 保留ReAG但不做决定性错误筛选；
  - 对不变量集合做留一（leave-one-out）分析。
- 在更大规模及更多域的轨迹上评测，包括多智能体冲突、环境动态变化、人工在线修复交互，以及多模态轨迹。
- 优化运行时：复用不变量检查中间结果、采用向量化检索相似步骤、增量式ReAG构建、按需展开；以及将“遍历全部不变量”改为“基于异常的由粗到细”搜索策略。

## 10. 总体评价

- AGENTSCOPE 提出了一种有说服力的研究范式：将不可解释的轨迹诊断变成一个“结构化抽象 + 局部验证 + 全局归因”的工程流程。虽然精确步骤级定位的绝对准确率仍然不高，但相对基线提升显著，使诊断不再完全依赖模型的长上下文直觉；其价值在于提供了一条可扩展、可审计的失败分析通道。
- 主要局限是“结构化抽象与神经函数的质量耦合”——如果ISR构造错误或不完整，后续不变量检测和归因都会受污染；论文没有量化这个误差传播过程。此外，数据集与实验虽然丰富，但缺少严格的统计和消融对照，使得“各组件到底贡献多少”仍不清晰。整体来看，这是一个概念上有创新、实现上有启发、但距离“可靠根因定位”的生产级工具仍有差距的工作。

## 摘要
大语言模型（LLM）智能体的失败往往包含多个相关错误，而非单一错误。现有归因方法通常识别负责任的主体、步骤或根本原因，但并未明确建模错误之间的依赖关系。我们提出EDGE，一种错误依赖图引导的多错误归因框架。EDGE从观察到的错误事件构建错误依赖图，并通过反事实推演验证可靠的因果子集。推断图引导两阶段LLM作为评判器的检测器进行错误归因，而干预验证的子图为解释和修复分析提供了更可靠的基础。在TRAIL和MAST上的实验表明，EDGE在大多数评估模型和设置中提升了类别级多错误归因性能。采用改编的Who&When风格提示的实验表明，该图在不同提示策略下均有所助益。这些结果表明，依赖结构是智能体失败的有用诊断先验，而非仅限于孤立的根因预测。

## Abstract
Large language model (LLM) agent failures often contain multiple related errors rather than a single mistake. Existing attribution methods usually identify a responsible agent, step, or root cause, but do not explicitly model dependency between errors. We introduce EDGE, an Error Dependency Graph-guided multi-Error attribution framework. EDGE constructs an error dependency graph from observed error events and validates a reliable causal subset through counterfactual rollout. The inference graph guides a two-stage LLM-as-judge detector for error attribution, and the intervention-validated subgraph provides a more reliable basis for explanation and repair analysis. Experiments on TRAIL and MAST show that EDGE improves category-level multi-error attribution across most evaluated models and settings. Experiments with adapted Who&When-style prompts show that the graph helps across prompting strategies. These results suggest that dependency structure is a useful diagnostic prior for agent failures beyond isolated root-cause prediction.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）智能体被广泛用于规划、检索、工具调用与推理等多步骤复杂任务。当任务执行失败时，最终结果只能表明"失败"这一事实，却无法解释失败是如何逐步演化的。为此，近年研究逐步转向"轨迹级失败归因"，即从执行的完整轨迹中定位出错的步骤与错误类型。
- **核心痛点**：
  - 现有归因方法（如 Who&When、AgentErrorBench 等）大多聚焦于**单一决定性错误**、关键步骤或单一根因（root cause），输出是"哪个智能体/哪一步/哪个根因导致了失败"。
  - 然而真实智能体失败轨迹中，错误往往以**级联（cascade）形式**出现：上游错误触发下游错误，多个错误之间存在依赖、传播和并行共存关系（如：上游触发错误 e1 → 下游错误 e3 → e4）。单错误归因会忽略这种结构性关联，导致归因不完整、解释不充分。
  - 已有的多错误标注基准（如 TRAIL）虽然提供细粒度的 span 级多错误标注，但此前方法并未显式利用错误之间的依赖传播结构。
- **论文提出的问题**：能否将多错误归因重构为"**依赖感知的诊断**"——即利用错误类别之间的依赖图作为先验，在一条失败轨迹上同时识别多个相互关联的错误，而非孤立地预测每个错误？
- **整体含义**：论文主张"依赖结构"是多智能体失败诊断中一种有价值的结构化先验；相比孤立的根因预测，依赖感知的方法不但能覆盖更多下游错误，还能为解释、修复与系统调试提供更可靠的因果依据。

## 2. 论文提出的方法论

### 2.1 核心思想

EDGE 的核心如图所示：将多错误归因视为"依赖感知的诊断"过程。其整体流程分四大模块：

1. 从带标注的错误事件中构造错误依赖图；
2. 通过反事实推演（counterfactual rollout）对候选因果边做干预验证；
3. 用验证后的图引导两阶段 detector 完成多错误归因；
4. 区分"用于预测的观测+验证混合图 Gτ"与"用于解释的纯干预验证图 Gv"。

### 2.2 问题形式化

- 一条轨迹（trace）记作 T = (s1, s2, ..., sN)，由执行时间排序的若干 span 构成。
- 轨迹被标注为一组错误事件 E(T) = {(cj, ℓj)}：cj 属于错误类别集合 C，ℓj 是该类别首次出现的 span 标识。
- 归因目标：对任意轨迹预测一组"类别-位置"对 ê(T)。
- 错误类别依赖图：G = (C, R)，其中节点是错误类别，有向边 A → B 表示"A 类型的错误会引发/推动 B 类型错误"。

### 2.3 观测图构建（Suppes 筛选 + CAPRI 剪枝）

- 用类别级二值变量 X_A(T) 表示类别 A 是否出现在轨迹 T 中；用 t_A(T) 记录 A 首次出现的 span 位置。
- **Suppes 筛选**：对每对有向类别对 A → B，要求满足：
  - **时间优先（Temporal Priority）**：在 A、B 同时出现的轨迹中，A 先出现的比例超过阈值；
  - **概率提升（Probability Raising）**：条件概率 P(B|A) − P(B|¬A) > 0。
  - 保留的边构成观测相关图 Gs。
  - 每条边的传播权重定义为时间优先比例与概率提升的**几何平均**：wS(A,B) = √(Prec(A,B) · ΔPR(A,B))。
- **CAPRI 风格剪枝**：在 Gs 的边集上进行有向无环图（DAG）空间的搜索（增边、删边、反转），以 AIC 风格评分最小化为目标，得到稀疏的**因果候选图 Gc**。

### 2.4 干预式图验证（反事实推演 + 效果评估）

- 针对候选图 Gc 中的每条边 A → B，选取 A 先于 B 出现的轨迹子集进行干预实验。
- 用 LLM-based 修复模块（patch library）在 A 首次出现的 span 处施加类别特定的补丁，消除错误 A。
- 保持所有工具输出**固定不变**，只让补丁所在 span 及其下游推理发生改变，以此实现受控反事实执行。
- 修复验证器（Judge A）判断 A 是否真的被消除；只保留 A 被成功消除的运行进入效果估计。
- 效果评估器（Judge B）判断反事实执行中 B 是否依旧存在；以风险差 Δ(A→B) = E[X_B(原始) − X_B(反事实)] 估计边效应。
- Δ 超过阈值 τval = 0.15 的边被保留，构成**经验验证的因果图 Gv**，作为可解释的传播结构。

### 2.5 推断图选择与两阶段图引导检测

- **推断图 Gτ** = （Gs 中 wS ≥ τ 的观测相关边）∪（Gv 中全部验证边）。对应权重 wAB 在验证边取效应值 max(Δ,0)，观测边取 Suppes 分数。
- **第一阶段（Stage 1）**：检测器接收轨迹、类别体系与完整图指导，输出初始错误集合 ê⁽¹⁾(T)。
- **第二阶段（Stage 2）**：将初始预测中的源类别集合 D(T) 沿 Gτ 传播到未检测到的目标类别，按聚合传播权重筛选出轨迹特定边子集 Rτ(T)；Judge 收到第二阶段的定向提示，只输出不在 D(T) 中的、图建议的下游错误。
- **合并**：最终预测 = 阶段 1 预测 ∪ 阶段 2 新增且类别不重复的条目。

### 3.2 对比方法与消融设置

- **Baseline**：与 EDGE 使用相同 backbone 与 prompt 的"不注入图"检测器。
- **+CG（静态图注入）**：把同样的边集以静态、不随轨迹变化的方式直接放到 prompt 中，单次 LLM 调用完成归因——用于检验图需要"动态双阶段消费"而非"简单可见"。

1. **EDGE 能显著提高多错误归因的类别级性能**：
   - 同一实验中，EDGE 在绝大多数 backbone 和评测设置下优于 baseline（TRAIL-GAIA 上加权 F1 最高提升超过 14 个百分点，TRAIL-SWE-Bench 上 GPT-oss-20B 提升达 20.58；MAST 上多模型提升 4.68–15.93 个点）。
   - 单一最常见例外是 QwQ-32B 的 MAST 加权 F1 轻微下降（-0.47）。

2. **错误依赖图的价值来自其结构，而非任意额外边信息**：
   - 随机边数匹配图在多数 backbone 上明显低于经过相关性/因果筛选的图；
   - 静态图注入（+CG）整体不稳定，而动态两阶段注入（由第一阶段预测激活相关子图）在 15 个骨干格中 14 个优于静态注入，说明"按轨迹剪枝的图条件化"是真正的操作杠杆。

3. **干预验证的因果图具有可迁移性与解释价值**：
   - 因果边能够揭示实际传播关系（例如 TRAIL 中"格式化错误→上下文处理失败"；MAST 中"行动-推理失配→过早终止"），为修复优先级提供可操作的拓扑依据；
   - 在 held-out 轨迹上重建图仍能带来增益，说明构图不依赖测试数据。

4. **对 Planning & Coord. 类别的收益最集中**：
   - 分错误实例的归因变迁显示，EDGE-only 检出的误差几乎集中于"规划与协调"类别（三个模型上 recall 分别提升 9.0→46.6、7.4→31.2、26.5→50.8），Reasoning 居中，System Execution 收益最低，符合图拓扑中 Planning 是下游目标、System 是上游源头的假设。

5. **存在 accuracy-recall 权衡**：
   - MAST 上多数模型的准确率下降（因大多数类别为阴性，分类分布不平衡），但召回率一致上升；EDGE 适合偏好"不要漏掉错误"的诊断场景，而不适合要求所有阴性案例高精度筛选的场景。

## 7. 优点

- **问题建模的创新性**：将"多错误归因"从独立多标签分类重构为"依赖感知的诊断"，用图的结构化先验覆盖孤立预测看不到的下游错误级联，填补了既有单根因范式与真实多错误传播之间的空白。
- **预测与解释分离**：用融合观测边的 Gτ 获取覆盖率，用纯干预验证的 Gv 提供因果解释——这种"覆盖性边"与"可解释边"的角色分离具有实际工程价值。
- **较强的诊断证据链**：图边经过了时序优先、概率提升、AIC 剪枝、受控反事实验证多重筛取，且验证中固定工具输出从而估计的是沿推理链的直接效应，在因果推断上比单纯的相关图更严谨。
- **多维度消融设计严谨**：随机图控制、静态 vs 动态注入、仅因果图 vs 观测+因果、阈值扫描、split 泛化检验等多层对照，使结论具有较强的可归因性；
- **提示策略无关性**：除自身的两阶段 prompt 外，还证明了图可以迁移到 Who&When 风格的不同提示格式（ALL-AT-ONCE 和 STEP-BY-STEP）中提升性能，说明图本身编码的依赖知识独立于某种单一 prompt 模板；
- 对 benchmark 的自然设定做了区分追踪（span 级 vs trace 级），适用范围更广。

## 8. 不足与局限

- **数据与标注瓶颈**：
  - 多错误标注语料稀少，单类别支撑不足，图只能由全量标注语料构建，推理时图固定，不能随轨迹变化；
  - MAST step 定位标注使用 GPT-4o 自动生成，覆盖率 82%，未完全人工验证，噪声会传导到时间优先估计与图结构，最终影响归因。
- **定位能力弱**：图依赖类别共现，因此对"哪些错误发生了"的类别预测帮助更大；对 span 级精确定位（尤其超长 SWE-Bench 轨迹）的提升有限，个别指标出现负值或持平。
- **验证受干预手段限制**：
  - 干预保持工具输出固定，测的是沿推理路径的直接效应，不能覆盖"工具重执行中介"的传播路径；
  - 部分候选边因共现轨迹数量不足无法充分验证，采用观测边补足覆盖，因此 Gτ 中的非验证边不保证因果性，在分布偏移下可靠性可能受影响。
  - MAST 反事实运行是 LLM 模拟而非真实重放，无法完全模拟真实 agent 行为（体现在 Judge-B not_observable 比例高达约 70%）。
- **Prompt/判定依赖 LLM**：修复验证与效果评估均依赖 LLM 评判，可能存在标注噪声、自偏置等问题；MAST 的 MAST "Conversation Reset"等类别的自动 step 定位准确率仍有待人工复核。
- **技术限制**：
  - 图注入是均匀应用于所有轨迹，没有依据模型置信度或任务复杂度做门控，故部分（低能力模型或复杂长上下文）场景下不增益甚至有害；
  - 方法对长上下文推理成本高：第二阶段额外增加单次调用，TRAIL 单次推理 GPU 小时（EDGE 5.23 vs baseline 3.25）增加了约 61% 的推理算力开销；
  - 单次运行没有误差条，缺少多次随机种子/重复试验以报告方差。
- **评价体系局限**：
  - MAST 的不均衡标签导致 accuracy 不敏感，作者也承认 69.5% 的"始终判负"分类器在 accuracy 上超过所有表格

即 accuracy 指标的区分度很弱，作者最终也更依赖加权 F1 与召回率来支撑结论；这提示在高度不均衡的多错误归因评测中，单一指标很容易掩盖真实能力差异，未来应设计对阴性样本数量不敏感的评测指标。

总体来看，EDGE 的上述不足决定了它的适用边界：**当任务目标是“尽量不遗漏相互关联的错误、并希望给出可解释的传播路径”时，该方法优势明显；而当任务对精确 span 定位要求极高、或需要在严格受控的因果干预下部署时，仍存在明显短板。**

## 9. 对未来研究与应用实践的启示

1. **多错误归因应摆脱“单根因”范式**：EDGE 的实验证据说明，依赖图所携带的结构信息能够系统性提升级联错误的检出率，这为后续构建“结构化诊断”类任务提供了方法论模板——错误之间的传播关系本身就是一类宝贵的训练/提示先验。

2. **图构建需要更高质量、更低成本的标注基础设施**：
   - 人工标注的 span 级多错误语料（TRAIL）显著优于自动标注（MAST 的 step 标注仅覆盖 82%），因此下一步应探索“人机协同”的自动标注管线：先由 LLM 生成候选标注，再由人工对时间关系与类别边界做低成本校验；
   - 可尝试用在线/交互式环境自动记录错误注入与传播日志，降低对事后标注的依赖。

3. **干预验证的覆盖面有待扩大**：
   - 当前反事实推演只固定工具输出、仅改变推理链，未来可结合“工具重放”“环境重置”等手段，验证通过工具调用副作用传播的错误边；
   - MAST 中约 70% 的反事实运行被判为 not_observable，说明 LLM 模拟 agent 行为的保真度是当前瓶颈，需引入更真实的执行环境或沙箱来替代模拟评估。

4. **图的使用方式值得继续挖掘**：
   - 当前图的注入仍是均匀、静态作用于所有轨迹，未来可探索按任务难度、模型置信度或上下文长度自适应地门控图注入，避免在简单轨迹或长上下文场景下产生噪声；
   - 将依赖图作为结构化损失或注意力偏置引入模型训练（而非仅在推理期注入 prompt），可能带来更稳定的增益；
   - 图的“预测用边（Gτ）”与“解释用边（Gv）”分离是一个极具工程价值的思路，可进一步发展为可配置的产品化诊断模块：用户可选择“追求覆盖率”或“追求因果可解释性”两种模式。

5. **评测体系需要补强**：
   - 建议后续工作报告多次运行均值和方差，以规避 LLM 非确定性带来的偶然性结论；
   - 对不均衡标签数据，应优先报告召回率、F1、ROC/PR 曲线下面积与类别分层结果，而非单独依赖 accuracy；
   - 位置定位（Localization）仍是薄弱环节，需要专门设计针对“类别正确但位置偏移”的容错性评测指标，或引入更细粒度的位置对齐方法（如基于编辑距离的 span 匹配）。

## 10. 总结

EDGE 的核心贡献在于：它第一次把“多智能体失败归因”从一个孤立的多标签分类任务，转化成了一个**“依赖图构建 → 干预验证 → 图引导双阶段检测”的可解释诊断闭环**。大量消融与跨模型实验表明，错误的类别依赖结构确实携带了超越单条轨迹观测的稳定先验，能够显著提升对下游级联错误的判别覆盖面，同时通过干预验证图提供可操作的因果解释。尽管它在精确定位、长上下文效率、干预真实性与评测可靠性上仍有明显局限，但作为“结构化、依赖感知的智能体诊断”方向的代表性工作，其方法论框架与实验设计具有重要的参考价值，也为后续研究指出了清晰的前进方向。

## 摘要
近年来，基于大语言模型（LLM）的多智能体系统发展迅速。尽管前景广阔，这类系统仍然脆弱，经常出现推理和协调错误，导致系统级失败。在此类系统中，失败归因依赖于追踪智能体之间的自然语言交互，以识别决定性错误，即纠正后能逆转系统失败的最早动作。存在两个关键挑战：1）浅层归因：现有方法通常仅捕获轻微偏差，例如不完整的检索或格式错误，这些可以通过验证机制纠正，但会错过系统失败的决定性原因。2）上下文退化：随着系统轨迹长度的增加，模型的推理能力迅速下降。为解决这些挑战，我们提出了DCFA，一种无需训练的失败归因框架。DCFA集成了一个全局模块，从系统轨迹构建结构化因果启发依赖图以识别初始决定性错误，以及一个局部模块，应用局部反事实启发推理来细化因果启发归因。在Who&When基准上使用六个LLM进行的实验表明，DCFA在步骤级准确性上比最先进的基线提高了最多8.27%。

## Abstract
Large language model (LLM)-based multi-agent systems have experienced rapid growth in recent years. Despite their promise, such systems remain fragile, frequently exhibiting reasoning and coordination errors that can lead to system-level failures. Failure attribution in such systems relies on tracing natural language interactions among agents to identify the decisive error, which refers to the earliest action whose correction can reverse system failure. There are two key challenges: 1) Shallow attribution: Existing methods often capture only minor deviations, such as incomplete retrievals or formatting errors, which verification mechanisms can correct, while missing the decisive cause of system failure. 2) Contextual degradation: As the length of the system traces increases, the model's reasoning ability rapidly deteriorates. To address these challenges, we propose DCFA, a training-free framework for failure attribution. DCFA integrates a global module that constructs structured causal-inspired dependency graphs from system traces to identify the initial decisive error, and a local module that applies local counterfactual-inspired reasoning to refine causal-inspired attribution. Experiments on the Who&When benchmark across six LLMs show that DCFA improves step-level accuracy by up to 8.27% over state-of-the-art baselines.

### 1. 论文的核心问题与整体含义（研究动机和背景）

论文聚焦于基于大语言模型（LLM）的多智能体系统（MAS）中的**失败归因（Failure Attribution）** 问题。尽管LLM多智能体系统在代码生成、知识检索、数据分析等领域应用广泛，但其系统级失败仍然频发，智能体之间的协调错误与推理错误会沿着系统轨迹（system trace）级联传播，最终导致整个工作流失败。

**核心任务是：** 在多智能体交互文本轨迹中，定位"决定性错误（decisive error）"，即**最早的那个动作，若对其做出纠正，即可逆转系统失败**。这与仅定位表面偏差或所有错误不同，更具可操作性和诊断价值。

论文明确指出两大核心挑战：
- **浅层归因（Shallow attribution）**：现有方法（包括ECHO、A2P等）倾向于识别可被验证机制纠正的微小偏差（如检索不完整、格式错误），而遗漏真正驱动系统失败的决定性原因（如基于不完整信息的事实编造）。
- **上下文退化（Contextual degradation）**：随着系统轨迹长度增加，模型推理性能急剧下降，例如在Who&When基准上，长度约10的轨迹准确率约为15%，而接近100步时准确率跌至近0%。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

论文提出了**DCFA（Dual-view Causal-inspired Failure Attribution）**，一个**免训练（training-free）** 的失败归因框架。该方法不依赖任何微调或额外训练，而是通过组合**全局因果启发归因**与**局部反事实启发增强**双视角推理来定位决定性错误。

整体框架包含两个核心模块：

**（1）全局因果启发归因模块（GCA，Global Causal-inspired Attribution）**

GCA旨在建模轨迹中交互间的深层依赖关系，避免浅层归因。其流程分三步：

- **轻微偏差识别（Minor Deviation Identification）**：通过MDI过程提取轨迹中所有潜在偏差交互，并给出简短原因说明（τe, Re）。该步不急于判定决定性错误，而是保留所有可能相关的交互供后续推理。
- **依赖图构建（Dependency Graph Construction）**：以检测出的偏差交互为中心，构建有向因果启发依赖图 G=(V,E)，节点为各交互步骤，有向边 (p,q) 表示 τp 前置且可能影响 τq。每条边需满足三个条件：
  - **时间性（Temporality）**：p < q，即前置步骤必须早于后置步骤发生。
  - **必要性（Necessity）**：Nec(τp→τq)=I[J(do(¬τp))=No]，即若移除τp，则τq应不再发生。
  - **充分性（Sufficiency）**：Suff(τp→τq)=I[J(do(τp))=Yes]，即确保τp的动作足以诱导τq的发生。
  - 只有同时满足上述三个条件的边才允许加入图结构，该保守规则过滤伪相关关系。
- **假设生成（Hypothesis Generation）**：基于系统轨迹、候选偏差、原因集合和因果依赖图，通过HG过程生成对决定性错误的初始假设（τ⋆, r⋆）。

**（2）局部反事实启发增强模块（LCE，Local Counterfactual-inspired Enhancement）**

LCE针对长轨迹上下文退化问题，在全局假设周围进行局部细化，具体过程如下：

- **双向依赖邻域搜索（Bidirectional Dependency Neighborhood Search）**：从全局假设 τ⋆ 的位置开始，在依赖图上分别向前（追踪下游传播效应）和向后（查找上游原因）贪心搜索。每一步选择具有最大正向边际贡献ΔS的邻接节点。
- **反事实启发评估（Counterfactual-inspired Evaluation）**：
  - 先通过Correct函数结合真值、错误事件及因果图构造完全纠正的轨迹 T̂ = {τ̂1, ..., τ̂N}；
  - 对每条交互τi构造反事实轨迹：eT(i) = {τ̂1,...,τ̂i, τi+1,...,τN}，即前i步纠正、后续保持原状；
  - 用Simulation过程模拟该反事实轨迹的结果Y(i)；
  - 用预训练编码器计算Y(i)与真值Ŷ的余弦相似度S(τi)=Cos(Enc(Y(i)), Enc(Ŷ))；
  - 定义纠正第i步的边际影响ΔS(τi)=S(τi)−S(τi−1)。
- **决定性错误裁决（Decisive Error Decision）**：将正向候选集、反向候选集与全局假设合并为最终局部候选集Tc，在局部范围内进行DED决策，最终输出决定性错误 τ*。

**核心思想总结**：先用全局因果图进行宽范围的结构化推理以产出假设，再围绕假设在局部邻域做反事实干预评估来细化，从而兼顾深层归因与长轨迹处理。

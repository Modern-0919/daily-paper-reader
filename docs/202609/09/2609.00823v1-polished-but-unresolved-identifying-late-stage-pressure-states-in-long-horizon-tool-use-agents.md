## 摘要
长程工具使用智能体不仅需要搜索和规划，还需要决定何时结束。我们研究了后期压力状态，在这种状态下，智能体倾向于提交一个看似完整且精致但关键约束仍未解决的最终答案。我们首先训练了一个线性探针，表明这种压力状态可以从智能体的隐藏状态中识别出来。然后，我们沿着这个压力方向使用激活干预，发现转移隐藏状态会改变压力分数以及智能体是继续使用工具还是提前提交。通过受控上下文操作，我们进一步观察到，约束清晰度和动作映射可以缓解压力。基于这些发现，我们提出了探针感知压力缓解（PSPR），这是一种在中等压力下应用轻量级压力缓解方向并在高风险压力下转向结构化组织的插件。在多个长程基准上的实验表明，我们的方法 consistently 增强了现有智能体方法的性能。

## Abstract
Long-horizon tool-use agents need not only to search and plan, but also to decide when to finalize. We study late-stage pressure states, in which an agent is biased toward submitting a final answer that appears complete and polished while key constraints remain unresolved. We first train a linear probe to show that this pressure state is identifiable from the agent's hidden states. Then, we use activation interventions along this pressure direction and find that shifting the hidden states changes both the pressure score and whether the agent continues tool use or submits early. Through controlled context manipulations, we further see that the pressure is mitigated by constraint clarity and action mapping. Based on these findings, we propose Probe-Sensed Pressure Relief (PSPR), a plugin that applies lightweight pressure relief direction under moderate pressure and moves to structured organization under high pressure risk. Experiments on multiple long-horizon benchmarks show that our method consistently strengthens existing agent methods.

# 2. 方法论

## 2.1 核心思想

- 论文的核心假设是：**后期压力状态在模型的隐藏表示空间中线性可分**，且沿着该状态方向进行激活干预可以在因果层面改变智能体的行为（继续工具使用 vs. 提前提交）。
- 在此基础上，进一步探索两类能有效缓解压力状态的情境因素（**约束清晰度**和**动作映射**），并据此设计自动化的压力感知与干预插件。

## 2.2 关键技术细节

### （1）压力状态的定义与样本标注

- 使用三类行动边界状态构造对比数据集：
  - **PresC（pressure-driven commit）**：低约束满意度（Ssat ≤ 0.3）且高交付润色度（DPS ≥ 4）的最终提交边界 → 正样本；
  - **HealC（healthy commit）**：高约束满意度（Ssat ≥ 0.85）且高润色度的正常提交 → 负样本 N1，用于排除“最终提交”这一动作形式的混淆；
  - **ProdC（productive continue）**：虽存在未解决的约束但继续产出有效行动（非提交）的边界 → 负样本 N2，用于排除“任务难度/不完整性”的混淆。
- 每个边界用预填充后的**首 token 隐藏状态**表示，以聚焦于动作启动而非静态上下文编码。

### （2）线性探针（Linear Probe）

- 在选定的中间层（Qwen3-14B 用 layer 26），训练线性二分类探针，输入为首 token 隐藏状态 hᵀ / hᵗ，输出为压力分数。
- 核心评价指标为 AUROC = 0.916，PR-AUC = 0.921（主要设置下），表明压力状态与低压力状态可被清晰分离。

### （3）激活干预（Activation Intervention）

- 采用对比激活加法（CAA；Rimsky et al., 2024）构建压力方向：

  - v_PresC−HealC = μ(PresC) − μ(HealC)：对比两种提交形态，分离出“在未解决约束下结束”的压力成分；
  - v_PresC−ProdC = μ(PresC) − μ(ProdC)：对比压力驱动提交与有效继续；
  - 还进一步对 v_PresC−ProdC 执行线性概念擦除（residualization），移除通用“提交 vs. 继续”方向的成分（v_commit = μ(HealC) − μ(ProdC)），得到纯化的压力方向 v⊥。
- 干预方式：在生成当前动作的前 K 个 token 时，在指定的干预层添加或减去对应的方向向量（幅度固定为 α = 1）。

### （4）PSPR（Probe-Sensed Pressure Relief）插件

- **PSPR = 压力探针（在线监测） + 分级干预策略**。
- 在每个动作边界，用探针计算压力分数 sₜ = Probe(hₜ,₁)；依据两个预设阈值 a = 0.4、b = 0.65 执行三级决策：

  - sₜ < a：**不干预**；
  - a ≤ sₜ < b（中等压力）：**施加压力缓解方向（v_relief）**——在首 K 个生成 token 上做激活加法，将模型从高压状态移向低压状态；
  - sₜ ≥ b（临界高压）：**显式状态组织（explicit state organization）**——让模型暂停并重放用户查询，梳理约束满足状态、将不明确/未支持的约束转化为具体的下一步动作并追加到上下文再继续。
- 压力缓解方向的构建为：v_relief = μ_LP − μ_HP，其中 HP 集为 PresC 节点，LP 集为对 ProdC 节点附加“约束澄清 + 动作映射”后、在下一有效生产行动边界收集的激活（而非附加边界本身）。

# 6. 主要结论与发现

- **后期压力状态是真实可检测的**：隐藏空间中可被线性探针分离（AUROC ≈ 0.92），且跨模型、跨基准可复现。
- **压力状态有因果行为影响力**：沿压力方向做减法干预可提升约束满足（如 CS 从 0.21→0.25）、降低下一节点压力分数、提升有效继续率；反向加法则降低性能。残差化后的纯压力方向仍保持同样的行为趋势。
- **约束清晰度与动作映射是有效缓解因子**：单独给予约束澄清或动作映射都能降低压力、提升继续与修复行为；两者结合效果最佳（压力从 0.62 降至 0.13，修复率升至 0.85）。注意分析了注意力权重，确认模型确实在使用附加信息。
- **PSPR 是一种有效且轻量级的插件**：在 DeepPlanning-Travel、DeepPlanning-Shop、TravelPlanner 上一致增强 CoT、ReAct、Reflexion 1 的 CS、PS、CP 等指标，跨骨干模型（Qwen3-14B/32B、OLMo-32B）与跨语言（中/英）均成立。
- **触发时机重要**：随机触发表明效果下降；周期触发虽略有效但明显弱于基于压力信号的 PSPR——说明**干预内容与干预时机的正确组合**才是完整增益来源。

# 7. 优点

- **研究角度新颖**：将智能体“过早提交导致约束不满足”的失败从行为层面推进到内部表示层面，识别出一个新的、可量化、可干预的状态概念，具有较大的学术新颖性。
- **证据链完整且层层递进**：从行为证据（图 1）→ 表示可分离性（探针）→ 因果干预（激活控制）→ 情境机制（约束清晰度 / 动作映射）→ 落地插件（PSPR），逻辑链条严密。

- **插件设计克制且实用**：PSPR 采用三级分级干预，在低、中、高风险下分别使用“不干预 → 轻量激活干预 → 显式组织”，兼顾效果与开销；显式组织在 PSPR 内为模型自生成，摆脱了对测试时 oracle 标注的依赖。
- **结果报告较透明**：包含消融、时机控制、跨语言验证、bootstrap 置信区间与执行成本分析，提升了可信度。

# 8. 不足与局限

- **应用范围受限**：方法只在文本型、结构化、约束可验证的规划任务中验证；对开放式、动态变化、多模态代理环境尚未涉及。
- **依赖可检查的开源模型**：PSPR 需要访问模型隐藏状态以进行探针监测与激活干预，因此无法直接适用于闭源 API 模型（如 GPT-4 级别接口），适用范围有限。
- **额外离线标注成本**：需提前构造探针与激活方向数据集，依赖 Gemini 等外部 LLM 教师标注与人工审计，引入额外的非平凡成本和潜在的标注偏差风险。
- **绝对性能有限**：在困难的长程规划基准上，即使 PSPR 带来一致的相对提升，各方法在严格案例准确率 (Acc) 上几乎为零（如 Qwen3-14B 组），表明底层模型仍远未能可靠解决该类任务；PSPR 的增益更像“从非常差到略好”而非“从可用到好用”。
- **机制完备性声明不过度**：作者亦明确承认，预提交失败可能还来自早期规划错误、证据丢失、上下文损失或工具误差等；后期压力状态并不是该类失败的充分或唯一原因。
- **阈值选择的启发式性质**：a = 0.4、b = 0.65 虽在多个设置间固定，但作者承认其为“实验默认值”而非全局最优，在不同风险偏好或场景下需要重新校准。
- **算力信息缺失 + 可复现性不足**：未提供 GPU 资源、训练时长等关键信息，也未公开代码或 rollout 细节，影响第三方复现进度。
